## 0. 一句话结论

在 28 篇文献的覆盖范围内，**"存量-流量聚合空间建模"**、
**"真实人类被试处于仿真闭环内"**、**"LLM 合成智能体与真人同驻同一仿真环境"**
这三个要素**分别都有成熟研究**（分别对应 A/B/C 三条线），
但**三者的交集在本语料中没有任何一篇文献同时具备**
——尤其"真人 + 合成体在同一空间流量仿真中协同推演"未见实例。
这正是本研究定位的缺口。

## A. 存量-流量 / 系统动力学空间建模

### A.1 已达到的成熟度

存量-流量范式在系统动力学中已有严格的数学基础。
[Baez2022_StockFlowDiagrams] 用范畴论为存量-流量图给出**组合式语义**，
使系统动力学模型可以被形式化地组合与验证——这说明"存量 + 流量"
不只是工程近似，而是有严格数学对象支撑的建模语言。
这对本研究的意义是：本项目在
[`docs/model/存量-流量模型规范.md`](../model/存量-流量模型规范.md)
中写下的守恒方程与流量合成规则，可以借用其语义框架做**合法性检查**，
而不必自创一套记号。

在**人流/旅游治理**方向，[Lyu2025_OvertourismSystemDynamics] 是最接近本项目的
应用范例：它用系统动力学刻画过度旅游的存量演化，并结合多目标优化给出
可持续平衡策略。这证明"用聚合存量刻画人群压力并评估治理策略"是可行的研究路线。
但其粒度是**目的地宏观管理**，没有空间分区，也没有真人参与回路。

在城市系统尺度，[Raimbault2020_UrbanScienceDynamics] 论证了城市系统的
**多尺度动力学**与以城市科学支撑治理的框架。这为本项目的"聚合单元 + 多尺度"
立场提供了学科合法性，但其尺度是**城市间**（城市体系），而非**场地内人流**。

在平台化方向，[Herzog2025_UrbanModelPlatform] 提出面向城市数字孪生的
公共建模与仿真基础设施。值得注意的是：这代表的是**数字孪生（高保真）路线**，
与本项目"以聚合建模降低空间复杂度"的取向**相反**，因此它是本项目的有力**对照**，
而非同类工作。

### A.2 参与式与系统动力学的结合

[Martin2020_CommunitySystemDynamics] 把社区参与式系统动力学用于
机器学习的问题界定，让利益相关者参与**建模过程**；
[MalardAdam2023_ParticipatoryModelling] 以参与式方式共同构建农业系统的耦合模型。
两篇共同说明"参与式 + 系统动力学"的组合**已有传统**（companion modelling）。

**但关键区别在于参与的时点**：这两篇的参与发生在**建模/问题界定阶段**
（一次性、离线），而本研究要求参与发生在**仿真运行之中**
（每轮实时决策并影响状态）。这是 A 线的**结构性空白**。

### A.3 A 线小结

| 已成熟 | 空白 |
|---|---|
| 存量-流量的严格语义 [Baez2022] | 与**实时**参与式实验结合 |
| 人流/旅游的存量-流量治理应用 [Lyu2025] | 空间分区粒度下的人流治理 |
| 参与式 + 系统动力学传统 [Martin2020, MalardAdam2023] | 参与发生在**仿真运行时**而非建模阶段 |

## B. 人在回路（HITL）与参与式仿真

### B.1 B 线中与本项目最接近的两篇

**[Ni2024_LiPUPMA]** 提出以**居住体验为中心**的
"living-in-the-loop"多主体参与式城市规划框架。这是本语料中
**与本项目最接近的先行工作**：同样主张把人置于规划回路中并采集体验数据。
差异在于：它**未采用存量-流量空间模型**，
且"合成智能体与真人同场协同"不是其重点。
→ 本项目相对它的增量应明确表述为：**空间存量-流量聚合层 + 人机同场**。

**[Xuan2025_GenerativeAgentHITL]** 构建生成式智能体平台并以
**10 项用户研究**评估人-助手交互。其价值在于**平台化 + 用户研究实证**的方法论：
它示范了"让真人与生成式智能体共同参与实验"如何被系统性地设计与评估。
→ 本项目的实验设计（决策窗口、量表、对照）可直接借鉴其经验。
差异：其环境是**对话式交互**，不是空间人流决策。

### B.2 从真人行为反推偏好

[Suzuki2017_ParticipatoryUrbanSim] 用**逆强化学习**从参与者行为反推偏好，
驱动多主体参与式城市仿真。这正对应本研究的一项需求：
从被试的空间选择中估计**拥挤弹性、吸引力参数**，
从而替代传统的观测标定。其技术路线（从决策反推效用）可迁移到本项目的参数估计。

### B.3 人机一致性的方法论基石

[Argyle2022_OutOfOneMany]（"silicon sampling"奠基工作之一）用语言模型
条件化生成"硅样本"，并**比对合成体分布与真人样本分布**。
这是本研究核心问题之一——"合成智能体能否替代真人做空间决策"——
的**方法论模板**：把真人分布作为基准，测量合成体分布的偏移。
[Xie2024_LLMAgentTrust] 则进一步系统检验 LLM 智能体能否模拟**人类信任行为**，
其"合成体 vs 真人"的实验设计与统计口径同样是可迁移范式。

### B.4 潜在强相关但未核实

[Feygin2019_BISTRO] `[待核验]` 从文件名与标题看，是把**行为实验与交通仿真耦合**
的测试床。若核实成立，它将是"行为实验 + 流量仿真闭环"**最接近的先行工作**，
必须在论文的 related work 中正面处理。**在核实前不得引用。**

### B.5 B 线小结

| 已成熟 | 空白 |
|---|---|
| 人进规划回路并采体验 [Ni2024] | 回路中使用**存量-流量空间模型** |
| 真人+生成式智能体共同实验的方法论 [Xuan2025] | 空间人流决策场景 |
| 从行为反推偏好 [Suzuki2017] | —（可直接借鉴） |
| 人机分布比对范式 [Argyle2022, Xie2024] | 应用于**空间**决策 |
| 行为实验耦合交通仿真 [Feygin2019] `[待核验]` | — |

## C. LLM 合成智能体与社会仿真

### C.1 合成智能体的架构基础

[Park2023_GenerativeAgents] `[元数据未核实，但为 UIST 2023 著名工作]`
提出生成式智能体架构（**记忆流 - 反思 - 规划**），在虚拟小镇中涌现出可信社会行为。
这是本项目 LLM 智能体模块的设计起点。
[Park2024_SelfReportSimulation] 进一步用**真人自陈数据**为每个智能体建立
个体化人设，实现"个体级"模拟并在多项社会科学复现中取得较好一致性。
→ 这为本项目提供了**合成体 persona 的直接构造方法**：
以真实被试的量表/自陈数据塑造其数字替身，使"真人 vs 数字替身"的对照成为可能。

### C.2 国内平台：缺口的关键证据

[Piao2025_AgentSociety] `[元数据未核实]` 与 [Zhang2025_SocioVerse]
代表国内 LLM 合成智能体平台的最高水平（对应赛博ZJU / SocioVerse 一支），
后者以**千万级真实用户池**为基础构建社会仿真"世界模型"。

**这里有一个对本研究至关重要的观察**（作者推断，但由文献直接支持）：
SocioVerse 的"真实用户池"是用于**校准合成体分布**的，
而不是让真实用户**进入仿真回路做实时决策**。
即：**真人是数据源，不是回路中的决策者**。
这正是本项目所指出缺口的**直接文献证据**——
它表明即便拥有海量真实用户数据，现有平台的范式仍是"纯计算智能体运行"。

### C.3 LLM 与规划参与的交叉

[Zhou2024_LLMParticipatoryPlanning] 用大语言模型支撑参与式城市规划，
聚合公众意见辅助方案研判。它证明"LLM 进入规划参与"已是活跃方向，
但其处理对象是**文本意见**，而非**空间流量决策**——
这与本项目"人的选择直接作为流量注入"形成清晰区分。
[Xu2024_GenAIUrbanDigitalTwins] 综述了生成式 AI 在城市数字孪生中的
数据/情景/设计自动生成，可用于定位本项目在数字孪生谱系中的位置。

### C.4 C 线小结

| 已成熟 | 空白 |
|---|---|
| 合成智能体架构（记忆/反思/规划）[Park2023] | 与**真人同场**协同 |
| 个体化人设构造 [Park2024] | 面向**空间**决策 |
| 国内大规模平台 [Piao2025, Zhang2025] | 真人**在回路内**（现状仅作校准数据源） |
| LLM 参与规划 [Zhou2024] | 空间流量闭环 |

## D. 人群/人流仿真与数字孪生

### D.1 本范式要"替代"的经典路线

[Helbing1998_SocialForceModel] 是行人动力学的奠基工作（社会力模型）；
[Burstedde2001_CellularAutomatonApplications] 与
[Schadschneider2001_CellularAutomatonTheory] 建立了元胞自动机行人动力学
的理论与应用体系。这三篇共同构成**个体级、高工程成本**路线的经典文献，
是本项目在 motivation 中要**对照**的对象：
它们精确刻画个体物理移动，但需要大量微观轨迹数据标定，
且为单向推演，难以同步采集参与者决策与主观感知。

[Amirian2019_DataDrivenCrowdGAN] 用 GAN 从真实轨迹学习人群运动，
[Chen2024_SocialPhysicsDiffusion] 用社会物理约束引导扩散模型生成人群运动。
两篇代表**数据驱动**方向，其标定思路（用实测数据拟合行为）可迁移到本项目的
流量参数标定；但仍是微观/个体级建模。

### D.2 平台对照

[Wang2024_CrowdEgress] 是用于复杂人群行为与疏散研究的多主体仿真平台。
作为已有的人群仿真平台，其功能边界可用于界定本项目的差异化：
本项目不是"更强的个体仿真器"，而是**面向人机交互实验的聚合闭环环境**。
[Zaitsev2023_Cormas] `[待核验]` 是长期用于参与式/陪伴建模的老牌平台，
若核实，其参与式建模传统值得在流程设计上借鉴；
[Wang2021_DigitalTwinIntersection] `[待核验]` 是数字孪生对照案例。

### D.3 D 线小结

| 已成熟 | 空白 |
|---|---|
| 个体级行人动力学（社会力/元胞）[Helbing1998, Burstedde2001, Schadschneider2001] | 低成本聚合替代 |
| 数据驱动人群仿真 [Amirian2019, Chen2024] | 参数标定可迁移 |
| 人群仿真平台 [Wang2024, Zaitsev2023] | 面向**人机交互实验**的闭环 |

## 2. 缺口的结构化论证

### 2.1 四线能力矩阵

| 线索 | 低成本空间建模 | 真人进闭环 | 群体规模 | 主观感知 | 空间流量闭环 | 真人+合成体同场 |
|---|---|---|---|---|---|---|
| **A 存量-流量** | ✔ [Baez2022, Lyu2025] | ✘ | ✔ | ✘ | ✘ | ✘ |
| **B HITL 参与式** | ✘ | ✔ [Ni2024, Xuan2025] | ✘ | ✔ [Ni2024] | ✘ | △ [Xuan2025] |
| **C LLM 合成体** | △ | ✘ [Zhang2025 仅作校准] | ✔ | ✘ | △ | △ |
| **D 人流/数字孪生** | ✘ | ✘ | △ | ✘ | ✘ | ✘ |
| **本研究** | ✔ | ✔ | ✔ | ✔ | ✔ | ✔ |

### 2.2 三个子缺口（均有文献支撑）

- **G1 范式缺口**：存量-流量范式未与**实时**参与式仿真深度结合。
  证据：A 线的参与式工作均发生在建模阶段而非运行时
  [Martin2020, MalardAdam2023]；A 线的人流应用无参与回路 [Lyu2025]。
- **G2 闭环缺口**：规划参与式仿真缺"选择提交 → 聚合驱动 → 状态回传"的
  **空间性**动态闭环。证据：最接近的 [Ni2024] 未用存量-流量空间模型；
  B 线的真人闭环场景多为非空间 [Argyle2022, Xie2024]。
- **G3 混居缺口**：真人与合成智能体**共同驻留同一仿真环境**协同推演的案例有限。
  证据：C 线平台的真实用户数据仅用于**校准**而非进入回路 [Zhang2025]；
  C 线个体模拟为合成体独立运行 [Park2024]；
  B 线的真人+合成体工作在**非空间**环境 [Xuan2025]。

### 2.3 本研究相对最接近先行工作的增量

| 先行工作 | 它做到了 | 本项目增量 |
|---|---|---|
| [Ni2024_LiPUPMA] | 人进规划回路、采居住体验 | 引入**存量-流量聚合空间模型**；引入**合成智能体同场** |
| [Xuan2025_GenerativeAgentHITL] | 真人+生成式智能体共同实验、10 项用户研究 | 场景换成**空间人流决策**；决策直接**注入流量场** |
| [Zhang2025_SocioVerse] | 千万级真实用户校准的大规模仿真 | 真人从**数据源**变为**回路内决策者** |
| [Lyu2025_Overtourism] | 存量-流量用于人流压力治理 | 加**空间分区** + **真人闭环** |
| [Park2024_SelfReportSimulation] | 用自陈数据造个体化合成体 | 让合成体与**真人同场**推演并测**可替代性边界** |

## 3. 方法论启示（可直接采纳）

1. **人机一致性检验**：采用 [Argyle2022] / [Xie2024] 的分布比对范式，
   把"真人群体流量分布"作为基准，测量合成体分布的偏移量。
2. **合成体人设构造**：采用 [Park2024] 的自陈数据接地方法，
   用真实被试的量表数据塑造数字替身，从而实现严格配对对照。
3. **参数估计**：采用 [Suzuki2017] 的"从决策反推偏好"路线，
   从被试空间选择中估计拥挤弹性与吸引力参数，替代观测标定。
4. **实验平台设计**：借鉴 [Xuan2025] 的用户研究流程与量表设计经验。
5. **模型形式化**：采用 [Baez2022] 的存量-流量图语义做模型合法性检查。
6. **误差量化**：以 D 线个体模型 [Helbing1998, Burstedde2001] 为对照，
   量化聚合近似的宏观统计量误差（对应模型规范 §7 多尺度接驳）。
