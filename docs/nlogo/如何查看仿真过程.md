# 怎么看仿真过程（两种方式）

上一轮我用 **headless 模式**跑模型，所以你看不到任何过程——
headless 就是"无窗口、只出 CSV"，这是它的设计用途，不是故障。
现在给你两种**能看见**的方式。

---

## 方式一：NetLogo GUI（真实交互，可自己点按钮）

已经在运行了。窗口标题是
`model - NetLogo {F:\城规工作室\CJ 李昊\SF-HITL-Sim\_nlogo_run}`。

**用法**：

1. 切到 **Interface** 标签页（默认就是）
2. 点 **`setup`** → 铺开初始人群
3. 点 **`go`** → 开始推演，你会看到行人（turtles）向左右出口移动
4. 左侧 **`moving-pattern`** 下拉框可切换四种决策模式：
   - `Shortest route`（最短路径）
   - `Random follow`（随机跟随）
   - `BNE (mixed with RF)`（BNE 混合随机跟随）
   - `BNE (mixed with SR)`（BNE 混合最短路径）
5. `number-persons` 调人数、`door-width` 调出口宽度、`follow-radius` 调视野半径
6. 想看密度热力图，在 Interface 里把 patch 上色（或看右侧 plot）

**自己重新启动 GUI**（若窗口关了或想换模型）：

```powershell
Start-Process "D:\NetLogo\NetLogo.exe" -ArgumentList '"F:\城规工作室\CJ 李昊\SF-HITL-Sim\_nlogo_run\model.nlogo"'
```

> ⚠️ 注意：`D:\NetLogo\NetLogo.exe` 用的是**自带 Java 17**，这是对的。
> 但 `D:\NetLogo\netlogo-gui.bat` **不要用**——它优先用 PATH 上的 Java，
> 而本机 PATH 是 Java 8，NetLogo 7 需要 Java 17+，会失败。

## 方式二：网页播放器（三种模式一键对比，可拖动时间轴）

文件：`results/repro/nlogo_播放器.html`

**已用默认浏览器打开。** 这是一个**单文件、离线可用**的播放器
（不需要联网、不需要服务器，双击即可）。

**界面里能做什么**：

| 控件 | 作用 |
| --- | --- |
| 决策模式（下拉） | 在三种模式间秒切，直接对比疏散快慢 |
| 时间步（滑块） | 任意拖动到某一帧，逐帧查看 |
| ▶ 播放 | 自动播放动画 |
| 速度 | 慢 / 中 / 快 / 极快 |
| 数据卡片 | 剩余人数、已疏散、当前时间步、疏散进度% |

**图上元素**：

- **白色方块** = 行人（agent）
- **底色深浅** = 该格人数（越红越拥挤）
- **左右绿竖线** = 两个出口

**三种模式的疏散时长对比（800 人）**：

| 模式 | 疏散完成（步） |
| --- | --- |
| Shortest route | 34 |
| Random follow | 42 |
| BNE (mixed with RF) | 49 |

> 注意：这三种是 **800 人单次运行**（为了动画流畅），
> 与报告里 2000 人 × 50 次的统计结论**不是同一组数据**。
> 统计结论请看 `docs/nlogo/NetLogo模型运行与复现报告.md`。
> 人数少时随机性更大，所以此处三者的差距与大规模统计不一致属正常。

**重新生成播放器**：

```powershell
# 1) 导出逐帧空间数据（约 5 秒）
pwsh -NoProfile -File ".\scripts\run-nlogo.ps1" `
  -Model ".\_nlogo_run\spatial_model.nlogo" `
  -Experiment "viz_spatial" -Table ".\_nlogo_run\spatial_table.csv"

# 2) 生成 HTML 播放器
py -3.13 scripts\build_nlogo_player.py
```

## 为什么 headless 看不到过程：技术原因

NetLogo 有两个入口类：

| 入口类 | 行为 |
| --- | --- |
| `org.nlogo.app.App` | **图形界面**，有窗口、能看动画、能点按钮 |
| `org.nlogo.headless.Main` | **无界面**，只跑 BehaviorSpace 并写 CSV |

我上一轮用的是后者（为了批量跑 150 次实验并产出可统计的 CSV）。
两者是**同一个模型、同一套代码**，只是有没有窗口的区别。

**另外**：NetLogo 7 的 headless CLI **没有** `--command` 参数
（我实测报 `unknown argument: --command`），所以"跑一条自定义命令"
只能靠 GUI 的 Command Center，或者像本方案那样
把导出逻辑写成模型里的 reporter + BehaviorSpace 指标。

这就解释了网页播放器的数据是怎么来的：
在模型里加了两个 reporter（`viz-heat` 输出每格人数、
`viz-agents` 输出所有行人坐标，都编码成十六进制字符串），
作为 BehaviorSpace 的 metric 逐步导出，再转成 HTML。
