### 1.2 Mesa 4.0.0a0（个体级对照模型）

```powershell
# ✅已验证（本地源码 editable 安装）
py -3.13 -m venv .venv-mesa
.\.venv-mesa\Scripts\python.exe -m pip install -e ".\deploy\repos\mesa" -i https://mirrors.aliyun.com/pypi/simple/
.\.venv-mesa\Scripts\python.exe -c "import mesa; print('mesa', mesa.__version__)"
# 期望输出：mesa 4.0.0a0

# ✅已验证的最小可运行模型（注意必须是新 API）
@'
import mesa
from mesa.discrete_space import OrthogonalMooreGrid, CellAgent
from mesa.datacollection import DataCollector

class Walker(CellAgent):
    def step(self):
        n = list(self.cell.neighborhood)
        if n: self.cell = self.random.choice(n)

class M(mesa.Model):
    def __init__(self, n=120, rng=42):
        super().__init__(rng=rng)                    # 若在 PyPI 稳定版上运行，此处需改回 seed=
        self.grid = OrthogonalMooreGrid((8, 8), random=self.random, capacity=None)
        cells = list(self.grid.all_cells)
        for _ in range(n): Walker(self).cell = self.random.choice(cells)
        self.dc = DataCollector(model_reporters={"pop": lambda m: len(m.agents)})
    def step(self):
        self.agents.do("step"); self.dc.collect(self)

m = M(); m.step(); print("pop:", len(m.agents))
print("OK discrete_space + datacollection")
'@ | Set-Content -Encoding UTF8 _mesa_smoke.py
.\.venv-mesa\Scripts\python.exe _mesa_smoke.py
```

> ⚠️ **Mesa 4.0.0a0 破坏性变更（✅实测）**：`mesa.space` → `mesa.discrete_space`；`mesa.datacollector` → `mesa.datacollection`；`Model(seed=)` → `Model(rng=)`；`mesa.experimental.cell_space` 已提升为 `mesa.discrete_space`。照抄旧教程会直接 `ModuleNotFoundError`。
> ⚠️ Mesa 的 `Cell` **没有** `stock`/`flow` 字段（公开属性仅 `agents/capacity/connect/neighborhood/...`），单元人数须 `len(cell.agents)` 反推——**不要**指望它做存量-流量语义。

## 7. 已知坑清单（全部为本机实测结论，勿重复试错）

| # | 坑 | 现象 | 处置 |
|---|---|---|---|
| 1 | GitHub DNS 劫持 | `github.com`/`api.github.com` 解析到 127.0.0.1；`git clone` 失败 | 源码一律走 `pwsh -NoProfile -File ".\scripts\gh-fetch.ps1" -Repo "<owner/repo>" -DestDir ".\deploy\repos"` |
| 2 | aliyun 镜像缺包 | 装 `requests` 时失败 | 回退 `-i https://pypi.org/simple/` |
| 3 | `eclipse-sumo` wheel 150 MB | 镜像下载 ~4.7 MB/min，不实用 | **不需要**：本机已有 SUMO 二进制，只装 `sumolib`+`traci` |
| 4 | 裸 `python` 不可用 | 指向 WindowsApps 存根 | 一律用 `py -3.13` 或 venv 内的 `python.exe` |
| 5 | Mesa 4.0.0a0 API 变更 | `ModuleNotFoundError: mesa.space` 等 | 用 `mesa.discrete_space` / `mesa.datacollection` / `Model(rng=)` |
| 6 | Mesa 无聚合语义 | `Cell` 无 `stock`/`flow` | 存量-流量语义由本项目 `src/core/` 承担 |
| 7 | `oTree-org/oTree` 非框架本体 | 仓库内无 `pyproject.toml` | 框架用 `pip install otree`；该仓库仅作示例参考 |
| 8 | AgentSociety 无 key 不能导入 | `ValueError: AGENTSOCIETY_LLM_API_KEY is required` | 设占位 key 或真实 key |
| 9 | AgentSociety Windows Ray | 依赖声明排除 win32，代码路径依赖 Ray Task | 迁 WSL2，或不用其运行主干 |
| 10 | CityFlow 无 PyPI wheel | `No matching distribution found for cityflow` | 只能在有编译环境的机器上源码构建 |
| 11 | jupedsim / Vadere 等需求缺口 | 行人仿真无现成高星活跃平台 | 自研聚合层（本项目创新点） |
