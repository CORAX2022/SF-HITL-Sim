# 存量-流量空间模型形式化定义

> 本文档定义本项目仿真内核的数学模型。它是"人-AI 混合实验平台"的科学基础，
> 与具体实现语言无关。所有代码实现（`src/`）必须与本文档一致；
> 若实现需要偏离本文档，必须先修改本文档并说明理由。

---

## 1. 为什么要"存量-流量"而不是"个体行人"

传统人群空间仿真有三条主流路线，各自的工程代价如下：

| 路线 | 代表 | 空间粒度 | 主要代价 |
|---|---|---|---|
| 精细地理数字孪生 | 3D 城市模型 + 传感器融合 | 建筑/构件级 | 建模与数据获取成本极高 |
| 个体元胞自动机 | 格子气、场域模型 | 元胞级（亚米） | 参数标定量大，情景难复用 |
| 行人动力学 | 社会力、RVO/ORCA | 个体级（连续） | 需微观轨迹数据标定，算力随人数增长 |

三者共同特点：**追踪个体的物理移动过程**。这带来两个后果：

1. **工程成本高**：空间建模精度与个体行为参数是两个独立的成本中心。
2. **难以闭环交互**：多数实现是单向推演（设定初值 → 跑完 → 看结果），
   没有把人的实时决策嵌进循环的位置。

存量-流量模型放弃了"个体在哪里"这一层信息，只保留：

- **存量**：每个空间单元内**有多少人**（聚合量，不是个体清单）
- **流量**：单位时间内**从单元 i 到单元 j 有多少人**

这恰好是系统动力学（Forrester 范式）的标准写法，也是城市交通规划中
O-D 矩阵与重力模型的语言。它的代价是丢失个体轨迹，收益是：

- 空间单元可以粗到"广场分区""街区""看台区块"，无需精细几何；
- 状态维度为 `N`（单元数）而非 `人数`，规模可控；
- 天然支持"人提交选择 → 聚合成流量 → 推进系统 → 状态回传"的闭环，
  因为**人的决策本身就是一种流量输入**。

本项目正是把最后这一点作为核心设计机会。

## 2. 系统定义

### 2.1 空间划分

将研究场地划分为 `N` 个**互不重叠的空间单元**（unit），记为
`U = {u₁, u₂, …, u_N}`。

单元可以是不规则多边形（广场分区、街区），不要求规则网格。单元之间的
**邻接关系**由有向图 `E ⊆ U × U` 给出：`(i, j) ∈ E` 表示"从 i 可直接前往 j"。

- `E` 允许不对称（如单向通道、扶梯）。
- 允许 `(i, i) ∈ E` 表示单元内停留（自身滞留）。
- 单元属性：面积 `A_i`、容量上限 `C_i`、类型 `t_i`（入口/通道/停留区/出口）。

> 复杂性控制：`N` 通常在 10–100 量级，远小于个体模型的状态维度。

### 2.2 状态变量

系统在时刻 `t` 的状态为：

```
x(t) = [x₁(t), x₂(t), …, x_N(t)]ᵀ ,   x_i(t) ≥ 0
```

`x_i(t)` 为单元 `i` 在时刻 `t` 的存量（人数）。这是**唯一的系统状态**。

总人数守恒（封闭系统假设）：

```
Σ_i x_i(t) = M(t) ,   M(t) 为场内总人数
```

若允许人员进出场地（入口流入、出口流出），则 `M(t)` 可变，见 §2.4。

### 2.3 流量与更新方程

单位时间步 `Δt` 内，从 `i` 流向 `j` 的人数为 `f_ij(t) ≥ 0`。

存量更新遵循**离散守恒律**：

```
x_i(t+1) = x_i(t) − Σ_{j≠i} f_ij(t) + Σ_{j≠i} f_ji(t) + b_i(t) − d_i(t)
```

其中 `b_i(t)` 为外部流入（入口进入），`d_i(t)` 为外部流出（离开场地）。

**守恒性约束**（离场量不能超过存量）：

```
Σ_{j≠i} f_ij(t) ≤ x_i(t)
```

且 `f_ij(t) = 0` 当 `(i,j) ∉ E`（不可达则无流量）。

> 关键区别：此处没有"每个个体选择去向"的过程，只有**聚合流量的直接计算**。
> 这正是该范式降低复杂度的机制。

### 2.4 边界条件

场地开放时，引入虚拟外部节点 `u₀`（场外）：

- 入口流入 `b_i(t)`：由外部到达过程驱动，可设为时变泊松过程或实测到达率曲线；
- 出口流出 `d_i(t)`：由单元"离开倾向"与吸引力决定；
- 需求总量 `D(t)` 可由场景脚本给定（如集会散场曲线）。

## 3. 流量生成机制（三类驱动）

流量 `f_ij(t)` 由三类驱动**叠加**而成。这是本项目实现"人-AI 混合"的技术接口。

### 3.1 结构化驱动（背景人流）

基于**重力/熵最大化**的经典形式：

```
         x_i(t) · p_i(t) · Attr_j(t) · exp(−β · c_ij)
f_ij^bg = ────────────────────────────────────────────────
          Σ_{k∈N(i)} Attr_k(t) · exp(−β · c_ik)
```

- `p_i(t) ∈ [0,1]`：单元 `i` 中"将要移动"的比例（移动倾向），
  可由单元类型、拥挤度、时段决定；
- `Attr_j(t)`：单元 `j` 的吸引力（目的地效用）；
- `c_ij`：通行成本（距离/时间/拥挤代价）；
- `β`：成本敏感度参数（离散选择模型中的尺度参数）；
- `N(i)`：`i` 的邻居集合。

该式确保 `Σ_j f_ij^bg ≤ x_i(t) · p_i(t)`，满足守恒约束。

### 3.2 人类被试驱动（Human-in-the-loop 的核心）

真实参与者在每一轮中被要求**提交一个空间选择**：

```
h: (参与者) → 目标单元 j* ，或"原地不动"，或"离场"
```

所有参与者的选择被**聚合**为一个流量增量：

```
f_ij^human(t) = Σ_{参与者 a：所在单元 = i，选择目标 = j} 1 · w_a
```

`w_a` 为参与者权重（默认 1；可扩展为代表性权重，使小样本外推到总体）。

**这是本研究的关键科学接口**：个体的主观决策不是被模型预测的，
而是作为**外生输入**注入流量场。模型无法"猜错"人的意图，
因为意图是直接采集的。

### 3.3 合成智能体驱动（LLM 合成主体）

大语言模型驱动的合成智能体 `a` 依据其**人设（persona）+ 记忆 + 当前空间状态**
产出选择，其贡献与人类同构：

```
f_ij^llm(t) = Σ_{合成智能体 a：所在单元 = i，选择目标 = j} w_a
```

因此人类与合成智能体在数学上**完全同权**——二者都是"流量决策者"。
这使"真人-合成体混杂实验"成为可能，也便于做对照：
同一场景下替换人类/合成体的比例，观察系统演化差异。

### 3.4 合成总流量

```
f_ij(t) = f_ij^bg(t) + f_ij^human(t) + f_ij^llm(t)
```

随后按 §2.3 的守恒律更新状态。若出现超额（`Σ_j f_ij > x_i`）或
容量越界（`x_i > C_i`），通过 §4 的约束层处理。

---

## 4. 约束与拥挤处理

### 4.1 容量约束

单元容量 `C_i` 反映物理容纳能力。当 `x_i > C_i` 时，触发：

- **拥挤惩罚**：提高该单元的通行成本 `c_ji`（对进入方向），
  即 `c_ji ← c_ji · (1 + γ · max(0, x_i/C_i − 1))`，
  使后续流量自然绕行（闭环负反馈，无需外部干预）；
- **排队与阻挡**：若 `x_i ≥ C_i^hard`，则 `f_ji = 0`（不可再进入）。

### 4.2 流量守恒投影

当三类驱动叠加后违反 `Σ_{j≠i} f_ij ≤ x_i`，按比例投影（proportional
projection）到可行域：

```
f_ij ← f_ij · min(1, x_i / Σ_{j≠i} f_ij)
```

该投影保持各流向的相对比例，是保证仿真不发散的关键数值保障。

### 4.3 数值稳定性

显式更新的稳定性条件（Courant-Friedrichs-Lewy 类比）：

```
Δt · max_i (Σ_j f_ij / x_i) ≤ 1
```

实践中取 `Δt` 使单步迁移比例不超过 20–30%。

## 5. 反馈通道（闭环的另一半）

闭环要求**仿真状态回传参与者**。回传内容设计为三层：

| 层次 | 内容 | 用途 |
|---|---|---|
| 客观状态 | 各单元当前存量 `x_i`、拥挤度 `x_i/C_i`、可达性 | 让参与者做下一步决策 |
| 相对定位 | 参与者自身所在单元、他人选择的聚合分布 | 制造社会信息条件 |
| 历史轨迹 | 前几轮的状态演化曲线 | 支持策略性决策 |

回传**不得泄露其他参与者的个人身份信息**，仅呈现聚合量。

闭环时序（一轮）：

```
    ┌──────────────────────────────────────────────────────────┐
    │                                                          │
    ▼                                                          │
 ① 呈现状态 x(t) 给参与者与合成智能体                            │
    │                                                          │
 ② 决策窗口：参与者提交空间选择；LLM 智能体生成选择              │
    │                                                          │
 ③ 聚合为流量 f^human, f^llm，叠加背景流 f^bg                    │
    │                                                          │
 ④ 约束投影 + 守恒更新 → x(t+1)                                │
    │                                                          │
 ⑤ 采集数据：选择、反应时、主观感知量表、理由文本                 │
    │                                                          │
    └──────────────► 回到 ①（t ← t+1）─────────────────────────┘
```

## 6. 数据采集（本范式的第二重产出）

存量-流量聚合模型的一个常被忽视的优势：**它使"决策"成为一等数据**。
每一轮可采集：

### 6.1 客观时序行为数据

| 字段 | 说明 |
|---|---|
| `participant_id` | 匿名化标识 |
| `round` | 轮次 `t` |
| `origin_unit` | 决策时所处单元 `i` |
| `choice_unit` | 选择的目标单元 `j*`（或 STAY / EXIT） |
| `decision_latency_ms` | 决策反应时 |
| `viewed_units` | 决策前查看过哪些单元（若前端埋点） |
| `world_state_snapshot` | 决策时的状态向量 `x(t)` 摘要 |

### 6.2 主观感知数据

| 字段 | 量表 |
|---|---|
| `perceived_crowding` | 感知拥挤度（Likert 1–7） |
| `perceived_safety` | 感知安全感 |
| `satisfaction` | 对当前所处空间的满意度 |
| `willingness_to_pay` / `preference_rank` | 空间偏好排序或支付意愿 |
| `free_text_reason` | 决策理由开放文本 |

### 6.3 可导出的分析量

- **揭示偏好 vs 陈述偏好**：客观选择（6.1）与主观评价（6.2）的偏离；
- **拥挤弹性**：`Δchoice / Δ(x_i/C_i)`，即人对拥挤的响应强度；
- **一致性检验**：同一场景下真人群体与 LLM 合成体群体的流量分布差异
  （这是"合成智能体能否替代真人"的直接实证）；
- **情景对比**：不同空间营建方案下的流量再分配与满意度变化。

> 这使平台同时是**推演工具**（预测情景）与**实证数据采集装置**（研究人）。

## 7. 与个体模型的接驳（可选扩展）

为兼顾精度，模型预留多尺度接驳点：

1. **局部精化**：对关键单元（如瓶颈通道）内部改用个体模型（社会力/元胞自动机），
   其边界条件由存量-流量模型的流量 `f_ij` 提供。
2. **流量校准**：用个体模型或实测数据拟合 `β`、`Attr_j`、`p_i` 等参数，
   再回到聚合层运行大规模情景。
3. **降维验证**：把个体模型在时间上聚合，检验其是否复现存量的宏观演化，
   从而验证聚合近似的有效性。

---

## 8. 模型局限（须在论文中明确声明）

1. **丢失个体轨迹**：无法回答"某个人走了哪条路"这类问题。
2. **空间单元粒度决定精度上限**：单元划得越粗，空间异质性损失越大。
3. **流量函数的设定依赖性**：重力模型的 `Attr_j`、`β` 需标定，
   否则结论对参数敏感。
4. **人群异质性被压缩**：存量是聚合量，组内差异（老人/儿童/轮椅使用者）
   需通过分组存量（多类 `x_i^g`）扩展，本版未展开。
5. **不替代安全工程仿真**：涉及踩踏力学等需要个体接触力的场景，
   必须回到个体模型。

## 9. 符号表

| 符号 | 含义 |
|---|---|
| `U`, `N` | 空间单元集合 / 单元数量 |
| `E`, `N(i)` | 单元邻接有向边集 / `i` 的邻居集合 |
| `x_i(t)` | 单元 `i` 在 `t` 时刻的存量（人数） |
| `M(t)` | 场内总人数 |
| `f_ij(t)` | `t → t+1` 从 `i` 流向 `j` 的人数 |
| `b_i, d_i` | 外部流入 / 流出 |
| `p_i(t)` | 单元 `i` 的移动倾向 |
| `Attr_j(t)` | 单元 `j` 的吸引力 |
| `c_ij` | `i → j` 的通行成本 |
| `β` | 成本敏感度 |
| `A_i`, `C_i`, `t_i` | 面积 / 容量 / 类型 |
| `w_a` | 决策者 `a` 的权重 |
| `Δt` | 时间步长 |
| `γ` | 拥挤惩罚系数 |

## 附：最小可运行示例（伪代码）

```python
# 状态
x = init_stock(N)                      # 各单元存量
for t in range(T):
    # ① 回传状态给人类与合成智能体
    broadcast(x)

    # ② 采集决策
    human_choices = collect_human_choices(timeout=window_ms)
    llm_choices   = llm_agents.decide(x)          # 依据人设+记忆
    bg_flows      = gravity_flows(x, p, Attr, c, beta)   # 背景流

    # ③ 聚合成流量
    f = bg_flows
    for (i, j, w) in human_choices + llm_choices:
        f[i][j] += w

    # ④ 约束投影 + 守恒更新
    f = project_conservation(f, x)                 # Σ_j f_ij ≤ x_i
    f = apply_capacity_penalty(f, x, C, gamma)     # 容量反馈
    x = x - f.sum(axis=1) + f.sum(axis=0) + b - d

    # ⑤ 采集数据
    log_round(t, x, human_choices, llm_choices, survey_responses(t))
```
