# 参考文献规范

> 本规范规定论文参考文献的**著录格式、BibTeX 字段映射、真实性核验流程**，
> 以及它与仓库内 [`paper/references.bib`](../../paper/references.bib) 的对应关系。
>
> 一句话原则：**格式可以后调，真实性不能后补。** 参考文献的第一要求不是好看，
> 而是"读者按这条信息能真的找到这篇文献"。

---

## 1. 采用标准

- **主格式**：GB/T 7714—2015《信息与文献 参考文献著录规则》，顺序编码制。
- **机器格式**：BibTeX（[`paper/references.bib`](../../paper/references.bib)），
  由 pandoc `--citeproc` 渲染。
- **中文稿**（《城市规划学刊》等）与**英文稿**（CEUS、CHI）分别使用对应 CSL 样式；
  当前仓库**尚未**放入 CSL 文件，获取与放置方式见 §7。

## 2. GB/T 7714—2015 基本格式

### 2.1 通用结构

```
主要责任者. 题名: 其他题名信息[文献类型标识]. 出版地: 出版者, 出版年: 引文页码.
```

- 责任者**不超过 3 位全部列出**，超过 3 位列前 3 位后加"，等"（英文加", et al."）；
- 题名后**必须**有文献类型标识（`[J]`、`[M]`、`[C]`、`[D]`、`[R]`、`[S]`、`[P]`、
  `[EB/OL]` 等）；
- 中文标点用全角，英文条目用半角标点；
- 每条以英文句点 `.` 结束。

### 2.2 文献类型标识

| 标识 | 类型 | 标识 | 类型 |
| --- | --- | --- | --- |
| `[M]` | 专著 | `[J]` | 期刊文章 |
| `[C]` | 会议论文（论文集内） | `[D]` | 学位论文 |
| `[R]` | 报告 | `[S]` | 标准 |
| `[P]` | 专利 | `[N]` | 报纸文章 |
| `[EB/OL]` | 电子公告/在线资源 | `[J/OL]` | 在线期刊 |

### 2.3 各类型示例（中文）

**期刊文章**

```
[1] 芮光晔, 黎子铭. 参与式规划设计驱动社区多维协同发展的机制与路径——以广东佛山顺德东风村为例[J]. 风景园林, 2026, 33(2): 59-67.
```

**会议论文**

```
[2] BAEZ J, LI X, LIBKIND S, 等. Compositional modeling with stock and flow diagrams[C]//EPTCS 380 (ACT 2022). 2023. DOI: 10.4204/EPTCS.380.5.
```

**预印本（在线资源）**

```
[3] WANG Y, GE J, COMBER A. An agent-based simulation model of pedestrian evacuation based on Bayesian Nash equilibrium[EB/OL]. (2022)[2026-10-15]. https://arxiv.org/abs/2211.14260v1.
```

**专著**

```
[4] 作者. 书名[M]. 出版地: 出版者, 出版年: 页码.
```

> 上述示例中的 `[2026-10-15]` 是"引用日期"，须在正式引用时替换为实际查阅日期。
> 本仓库内**没有任何专著条目**，示例仅说明格式，不得据此新增文献。

## 3. BibTeX 字段映射表

| GB/T 7714 元素 | BibTeX 字段 | 说明 |
| --- | --- | --- |
| 主要责任者 | `author` | 中文名 `姓 and 名`；英文 `Last, First and Last, First`；超过 3 位用 `and others` |
| 题名 | `title` | 保留原题名（含副题名）；`&` 写 `\&`；特殊字符用 LaTeX 转义 |
| 期刊名 | `journal` | 期刊文章必须 |
| 会议/论文集名 | `booktitle` | 会议论文必须 |
| 出版年 | `year` | 四位数字 |
| 卷 | `volume` | 无则留空并标 TODO |
| 期 | `number` | 无则留空 |
| 页码 | `pages` | 用 `--` 连接，如 `59--67` |
| 出版地 | `address` | 专著/会议录需要 |
| 出版者 | `publisher` | 专著/会议录需要 |
| DOI | `doi` | 不带 `https://doi.org/`，只写 `10.xxxx/xxxx` |
| 在线地址 | `url` | 预印本、在线资源必须 |
| 引用日期 | `urldate`（biblatex）或 `note` | BibTeX 无原生字段，写进 `note` |
| 预印本编号 | `eprint` + `archiveprefix` | arXiv 用 `eprint = {2211.14260v1}`、`archiveprefix = {arXiv}` |
| 文献类型 | 条目类型（见下表） | 由条目类型决定输出标识，不单设字段 |
| 语言 | `language` 或 `note` | 中文文献写 `language = {zh}` |
| 版本 | `edition` | 如 `2nd` |
| 译者 | `translator` | 中文译著需要 |
| 其他说明 | `note` | 用于"预印本""元数据未核验""数据源"等说明 |

### 3.1 条目类型 ↔ 文献类型标识

| BibTeX 条目类型 | GB/T 标识 | 适用 |
| --- | --- | --- |
| `@article` | `[J]` / `[J/OL]` | 期刊论文（有 DOI 时用 `[J/OL]` 并附 DOI） |
| `@inproceedings` | `[C]` | 会议论文 |
| `@book` | `[M]` | 专著 |
| `@phdthesis` / `@mastersthesis` | `[D]` | 学位论文 |
| `@techreport` | `[R]` | 报告 |
| `@standard` | `[S]` | 标准（部分 BibTeX 实现不支持，可用 `@misc` + `note`） |
| `@misc` | `[EB/OL]` | 预印本、数据集、网页 |

> **本仓库约定**：arXiv 预印本统一用 `@misc` + `eprint` + `archiveprefix`，
> 不用 `@article` 伪装成已发表期刊论文。

## 4. 各类型 BibTeX 与 GB/T 输出示例

### 4.1 arXiv 预印本

```bibtex
@misc{Wang2022_BNEEvacuation,
  author        = {Wang, Yiyu and Ge, Jiaqi and Comber, Alexis},
  title         = {An agent-based simulation model of pedestrian evacuation based on Bayesian Nash Equilibrium},
  year          = {2022},
  eprint        = {2211.14260v1},
  archiveprefix = {arXiv},
  note          = {第 6 章外部复现对象的方法学来源（NetLogo 实现，CC BY-SA 4.0）}
}
```

GB/T 7714 渲染（顺序编码制）：

```
[n] WANG Y, GE J, COMBER A. An agent-based simulation model of pedestrian evacuation based on Bayesian Nash equilibrium[EB/OL]. (2022)[引用日期]. https://arxiv.org/abs/2211.14260v1.
```

### 4.2 有 DOI 的期刊论文

```bibtex
@article{Simini2021_DeepGravity,
  author  = {Simini, Filippo and Barlacchi, Gianni and Luca, Massimiliano},
  title   = {A Deep Gravity model for mobility flows generation},
  journal = {Nature Communications},
  year    = {2021},
  doi     = {10.1038/s41467-021-26752-4}
}
```

GB/T 7714 渲染：

```
[n] SIMINI F, BARLACCHI G, LUCA M. A Deep Gravity model for mobility flows generation[J/OL]. Nature Communications, 2021. DOI: 10.1038/s41467-021-26752-4.
```

> 卷期页码缺失时**不得编造**，渲染结果就停在 `2021.`——这是可接受的，
> 但必须在 bib 中留有 `% TODO: 待核实` 注释，定稿前补全或确认期刊不要求。

### 4.3 会议论文

```bibtex
@inproceedings{Martin2020_CommunitySystemDynamics,
  author    = {Martin, Jr., Donald and Prabhakaran, Vinodkumar and Mitchell, Margaret},
  title     = {Participatory Problem Formulation for Fairer Machine Learning through Community Based System Dynamics},
  booktitle = {ICLR 2020},
  year      = {2020}
}
```

GB/T 7714 渲染：

```
[n] MARTIN D Jr, PRABHAKARAN V, MITCHELL M. Participatory problem formulation for fairer machine learning through community based system dynamics[C]//ICLR 2020. 2020.
```

### 4.4 中文期刊

```bibtex
@article{Rui2026_ParticipatoryCommunity,
  author   = {芮光晔 and 黎子铭},
  title    = {参与式规划设计驱动社区多维协同发展的机制与路径——以广东佛山顺德东风村为例},
  journal  = {风景园林},
  year     = {2026},
  volume   = {33},
  number   = {2},
  pages    = {59--67},
  language = {zh},
  note     = {题录与摘要经 NAPSTIC 核验（origin_id 7202988551）}
}
```

GB/T 7714 渲染：

```
[n] 芮光晔, 黎子铭. 参与式规划设计驱动社区多维协同发展的机制与路径——以广东佛山顺德东风村为例[J]. 风景园林, 2026, 33(2): 59-67.
```

> 中文条目**不写** `language` 的渲染结果（CSL 依据字符集自行判断）；
> `language = {zh}` 仅用于机器处理与后续排序。

### 4.5 带访问日期的在线资源

```bibtex
@misc{Herzog2025_UrbanModelPlatform,
  author        = {Herzog, Rico H. and Degkwitz, Till and Verma, Trivik},
  title         = {The Urban Model Platform: A Public Backbone for Modeling and Simulation in Urban Digital Twins},
  year          = {2025},
  eprint        = {2506.10964},
  archiveprefix = {arXiv},
  note          = {引用日期：待补（YYYY-MM-DD）}
}
```

> 引用日期须在正式引用时补齐；`paper/references.bib` 当前**未**逐条写访问日期，
> 属已知待办（见 §6.3）。

## 5. 真实性核验流程

### 5.1 四步核验法

```
① 索引定位 → ② PDF/出版方页面核实 → ③ 逐字段登记 → ④ 记录核验状态
```

**① 索引定位**：任何拟引用文献，必须先在仓库索引中有记录：

- [`docs/papers/index.json`](../../docs/papers/index.json)（28 篇，含本地 PDF）
- [`docs/papers2/index.json`](../../docs/papers2/index.json)（74 条，含中文摘要）

不允许"脑子里想到一篇就加进 bib"。

**② 核实来源**：优先级从高到低

1. 本地 PDF 首页/正文（`docs/papers/pdf/`、`docs/papers2/pdf/`）；
2. 索引中 `verified: true` 且标明"标题/作者/摘要取自 arXiv 或出版方 API 实际返回"；
3. 元数据页面（在当前网络下 **Crossref / OpenAlex / Semantic Scholar 不可达**，
   仅 arXiv 可直连；出版方页面能否访问取决于网络，见 README 的环境说明）。

**③ 逐字段登记**：按 §3 映射表填写；每个字段问一次"这是从哪看到的？"
答不出来就留空。

**④ 记录核验状态**：在 bib 条目上方写注释：

```bibtex
% 来源：docs/papers/index.json（verified: true；source_id: doi:10.xxxx/xxxx）
% TODO: 待核实：卷期页码未记录
```

### 5.2 三条铁律

1. **禁止凭记忆补 DOI、卷期、页码、作者顺序**。记忆是最不可靠的元数据来源。
2. **禁止把"看起来像真的"的条目写进 bib**。宁可缺一条，不可错一条。
3. **禁止用二次来源冒充一次来源**。转引的文献必须找到原文再引；
   找不到原文就不引。

### 5.3 不确定时如何标注

| 不确定的内容 | 处理方式 |
| --- | --- |
| 某个字段（卷期、页码、DOI）缺失 | 字段留空 + 条目上方 `% TODO: 待核实：<具体缺什么>` |
| 标题/作者本身可疑（如解析残片） | 用索引原样记录 + `% TODO` 说明可疑点，**不得自行"修正"** |
| 整条元数据未核验（`verified: false`） | 收入 bib 但标注 `% TODO`，正文引用时降级表述（如"有预印本报告称……"） |
| 元数据不足以构成条目（无标题/无作者） | **不进入 bib**，在 `paper/README.md` §7.4 登记排除原因 |
| 中文文献无 DOI | 不写 DOI，用 `note` 记录题录来源（如 NAPSTIC origin_id） |

### 5.4 中文文献的特殊处理

- 作者用中文姓名，不强行罗马化（如无权威英文名）；
- 期刊名用中文全称（《风景园林》《城市规划学刊》）；
- 无 DOI 时不编造，用 `note` 记录数据库题录号与核验来源；
- 作者英文译名若刊物要求，须以作者本人/期刊官网为准，不得音译臆造。

| 带 `% TODO: 待核实` 注释的条目 | **31 条**（40 条核心条目中，元数据已完整、无需 TODO 的为 9 条；详见 bib 文件内注释） |
| 被排除、禁止引用 | `Qiu2025_LockInHypothesis`、`Fang2021_FlowAggregation`、`Wang2021_DigitalTwinIntersection` |

> 两库去重后 40 条 = 索引一 25 条 + 索引二新增 15 条；
> 其中 CrowdEgress、Cormas、SocioVerse 三篇两库重复，取 papers2 的已核验版本。

### 6.2 key 命名规则

```
<第一作者姓><年份>_<短标题>
```

示例：`Baez2022_StockFlowDiagrams`、`Wang2022_BNEEvacuation`、`Piao2026_PolarizationNetworks`。

- `docs/papers/index.json` 中已存在的条目**直接沿用其 `id`**，以保证与
  [`docs/literature/文献综述.md`](../../docs/literature/文献综述.md) 的 `[条目 id]` 一致；
- 因此个别 key 的年份可能与条目 `year` 字段不同（如 `Baez2022_*` 的出版年为 2023），
  这种情况**在条目上方注释说明**，不得为了"好看"重命名 key；
- 重命名 key 属于破坏性变更，须按
  [`写作工作流.md`](写作工作流.md) §4.5 写 `BREAKING CHANGE`。

### 6.3 已知待办

1. **补齐 31 条 TODO**：逐条打开 PDF 或出版方页面核实，能补则补，不能补则降级表述；
2. **补引用日期**：在线资源（arXiv、URL）的访问日期统一补为实际查阅日；
3. **删除或修正可疑元数据**：如 `Baez2022` 第 5 作者记录为 `"Nicholas B. B. S."`，
   须以 PDF 首页为准；
4. **全库一致性检查**：确认正文 `[@key]` 与 bib 完全对应；
5. **文献综述回写**：`docs/literature/文献综述.md` 中 7 篇未核验条目的处理结论，
   必须同步到 bib（要么收入并核实，要么确认排除）。

### 6.4 检查命令

```powershell
# ① 正文引用的 key 是否都在 bib 中（先抽取再人工比对）
Select-String -Path paper/sections/*.md -Pattern '\[@([^\]]+)\]' -AllMatches |
  ForEach-Object { $_.Matches } | ForEach-Object { $_.Groups[1].Value } |
  Sort-Object -Unique

# ② bib 中还有多少 TODO 未处理
Select-String -Path paper/references.bib -Pattern '% TODO' | Measure-Object

# ③ 导出时验证引用可解析（无 warning 即通过）
pandoc build/manuscript-body.md -o build/manuscript.docx `
  --citeproc --bibliography=paper/references.bib
```

> 第 ③ 步的 `build/manuscript-body.md` 由
> [`paper/manuscript.md`](../../paper/manuscript.md) §4.1 的脚本生成。

## 7. 中文 GB/T 7714 样式的落地

pandoc 默认按英文样式渲染，投中文刊须显式指定 CSL 样式：

```powershell
pandoc build/manuscript-body.md `
  -o build/manuscript-gb.docx `
  --citeproc --bibliography=paper/references.bib `
  --csl=paper/templates/gb-t-7714-2015-numeric.csl
```

**当前状态**：`paper/templates/` 目录**尚未创建**，CSL 文件**尚未入库**。
落地步骤（需有网络的机器）：

1. 从 CSL 官方样式库或 Zotero 中文社区获取 `gb-t-7714-2015-numeric.csl`
   （GB/T 7714—2015 顺序编码制）；
2. 放入 `paper/templates/`，随仓库提交（文本文件，可 diff）；
3. 用一条中国知网/中文期刊的标准引文做回归测试，确认作者截断规则为"前 3 位 + 等"；
4. 在 `paper/manuscript.md` §4 的导出命令中固定该 `--csl` 路径。

> 在 CSL 文件入库前，**不得**在论文中声称已符合 GB/T 7714—2015 的排版；
> 只能说"著录字段按 GB/T 7714—2015 组织"。

## 8. 自查清单

**条目层**

- [ ] 每条都有索引来源（`docs/papers*/index.json` 的 id）；
- [ ] 每条都有文献类型对应的 BibTeX 条目类型；
- [ ] 超过 3 位作者用 `and others`，不手写全部作者；
- [ ] DOI 只写裸号，不带 `https://doi.org/`；
- [ ] arXiv 条目用 `@misc` + `eprint` + `archiveprefix`；
- [ ] 不确定字段留空且带 `% TODO: 待核实`；
- [ ] 中文条目有 `language = {zh}` 与题录来源 `note`。

**正文层**

- [ ] 每个 `[@key]` 都能在 bib 中解析；
- [ ] 引用位置紧跟判断，不挂段尾；
- [ ] 未核验文献没有被当作定稿论证依据；
- [ ] 转引已消除（一律引原文）。

**构建层**

- [ ] `pandoc --citeproc` 无未解析引用；
- [ ] 中文稿已挂 GB/T 7714 CSL（否则不声明符合标准）；
- [ ] 参考文献表顺序符合顺序编码制（按正文首次出现排序）。
