# 术语表

> 本表是论文写作的**术语唯一准绳**。正文中同一概念只允许一种写法；新增术语
> 必须先入表，再使用。首次出现时给中英对照，其后只用中文（引用文献原题名除外）。
> 风格规则见 [`风格指南.md`](风格指南.md)，引文规范见
> [`参考文献规范.md`](参考文献规范.md)。

## 使用说明

1. **左列**为论文正文使用的规范写法；不得使用其他变体（常见误写见文末 §3）。
2. **中列**为英文对应词；英文摘要与英文稿必须与中列一致。
3. **右列**说明定义与**本文的特定用法**——同一词在不同学科含义不同，
   本文只采用右列口径。
4. 符号（如 `x_i`、`f_ij`）定义见
   [`docs/model/存量-流量模型规范.md`](../../docs/model/存量-流量模型规范.md) §9，
   本表不重复符号表。

## 1. 核心术语

| 中文术语 | English | 定义与本文用法 |
| --- | --- | --- |
| 存量 | stock | 某一空间单元在某一时刻内的人数（聚合量，不是个体清单）。本文唯一的状态变量，记 `x_i(t)`；不用"人口""密度"替代。 |
| 流量 | flow | 单位时间步内从一个空间单元转移到另一个单元的人数，记 `f_ij(t)`；单位是"人/步"，不与"流率（人/秒）"混用。 |
| 空间单元 | spatial unit | 场地划分出的互不重叠的区域（多边形、街区、看台区块等），记 `U = {u₁,…,u_N}`；演示场景为 12 个。不使用"格子""网格"（除非指元胞自动机）。 |
| 跨单元流量 | inter-unit flow | 单元 `i` 到单元 `j` 的有向流量，要求 `(i,j) ∈ E`；不可达则恒为 0。与"单元内停留（自环）"相对。 |
| 守恒方程 | conservation equation | 离散守恒律 `x_i(t+1) = x_i(t) − Σ_{j≠i} f_ij + Σ_{j≠i} f_ji + b_i − d_i`；本文同时要求离场量不超过存量（`Σ f_ij ≤ x_i`）。 |
| 约束投影 | constraint projection | 当叠加流量超过可流出量时，按比例缩放使约束重新成立：`f_ij ← f_ij · min(1, x_i/Σ f_ij)`。本文强调它是**不可跳过**的数值保障，不是可选项。 |
| 容量 | capacity | 单元物理容纳能力上限，记 `C_i`。本文的容量是**软约束**：超容时提高进入成本、超硬容量时禁止进入，但存量本身不被截断（见 06 章 §6.5）。 |
| 吸引力 | attractiveness | 目的单元的效用项，记 `Attr_j(t)`；进入重力流的分子，可随拥挤与时段变化。 |
| 人在回路 | human-in-the-loop (HITL) | 真实人类在仿真运行中实时做决策、其决策反过来影响仿真状态的实验范式。本文特指"每轮决策窗口内提交空间选择"这一具体形式。 |
| 参与式仿真 | participatory simulation | 利益相关者参与仿真的总称。本文限定为"参与发生在**仿真运行中**"，以区别于建模阶段的参与式建模。 |
| 合成智能体 | synthetic agent | 由大语言模型或规则驱动、按人设与状态产出决策的虚拟主体。本文中与人类**同权**进入流量场；规则脚本体须明示为"规则背景体/占位"，不得称为合成智能体。 |
| 人机协同 | human–machine collaboration | 真人与合成智能体在同一仿真世界中共同推演、共同影响系统状态。本文不写作"人机协作"（引用原题名除外）。 |
| 统一决策协议 | unified decision protocol | 真人与合成智能体共用的结构化消息格式（`actor_id`、`actor_type`、`origin_unit`、`choice`、`weight` 等）。核心约定：`actor_type` 只用于分组分析，不改变内核计算。 |
| 决策窗口 | decision window | 一轮中允许决策者提交选择的时长 `window_ms`；超时按 STAY 处理并记录 `timed_out`。 |
| 轮次生命周期 | round lifecycle | 一轮的完整时序：广播状态 → 开启决策窗口 → 汇总 → 聚合流量 → 投影与推进 → 落盘 → 终止判定。全局同步点只在投影与推进之间。 |
| 闭环 | closed loop | "呈现状态 → 采集决策 → 聚合流量 → 约束投影与推进 → 状态回传"的循环。本文的"闭环"必须同时含**人的决策**与**状态回传**，缺一不算。 |
| 揭示偏好 | revealed preference | 从被试的**实际选择行为**推断的偏好（对应第 6.1 类客观数据）。 |
| 陈述偏好 | stated preference | 被试通过量表、排序或支付意愿**自陈**的偏好（对应第 6.2 类主观数据）。 |
| 拥挤弹性 | crowding elasticity | 选择对单元拥挤度变化的响应强度，`Δchoice / Δ(x_i/C_i)`；本文要求由实验估计，而非观测标定。 |
| 人机一致性 | human–machine consistency | 同一场景下真人群体与合成体群体的流量分布差异程度。本文把它作为**待检验**的效度指标（H3），不作为默认前提。 |
| 标定 | calibration | 用观测或实验数据估计模型参数（`Attr_j`、`β`、`p_i` 等）。本文区分"观测标定"与"实验估计"两条路径。 |
| 复现 | reproduction | 在独立环境中重跑他人模型/实验并比对统计量。本文的复现对象是第三方 NetLogo 疏散模型（150 次运行），须同时报告复现边界。 |
| 存量—流量图 | stock–flow diagram | 系统动力学中以存量、流量与因果连接描述系统的图形化建模语言；本文借用其语义框架为守恒方程做合法性参照。 |
| 系统动力学 | system dynamics | 以存量、流量、反馈回路刻画系统演化的建模范式（Forrester 传统）。本文的聚合建模立场源自该范式。 |
| 基于智能体的建模 | agent-based modelling (ABM) | 以自主个体及其交互为基本单位的建模范式。本文的个体级对照（第三方疏散模型）属于 ABM；本平台内核**不是** ABM。 |
| LLM 智能体 | LLM agent | 以大语言模型为决策核心的智能体。本文中它是"合成智能体"的一种实现；当前代码中尚未实现，以规则体占位。 |

## 2. 补充术语（正文中会出现）

| 中文术语 | English | 定义与本文用法 |
| --- | --- | --- |
| 存量—流量模型 | stock–flow model | 以空间单元存量为状态、跨单元流量为更新的聚合模型；本文的模型总称。 |
| 背景流 | background flow | 由重力/熵最大化生成的结构化流量 `f^bg`，代表"无人干预时的自发人流"。 |
| 重力模型 | gravity model | 以目的地吸引力与通行成本（含阻抗衰减）解释流量的经典模型；本文 `f^bg` 的形式基础。 |
| 通行成本 | travel cost | 单元间的移动阻抗 `c_ij`（距离/时间/拥挤代价）；拥挤时被动态抬高。 |
| 移动倾向 | mobility propensity | 单元中"将要移动"的人数比例 `p_i`；由单元类型、拥挤度、时段决定。 |
| 硬阻挡 | hard block | 单元存量达到硬容量时禁止再进入（`f_ji = 0`）；与"拥挤惩罚"合称容量反馈。 |
| 状态快照 | state snapshot | 回传决策者的聚合状态（各单元存量、容量、利用率、类型与位置）；**只含聚合量**，不含个人身份信息。 |
| 代表性权重 | representativeness weight | 决策者的权重 `w_a`，用于把小样本外推到群体规模；默认 1，须同时报告未加权结果。 |
| 混合比例 | mixing ratio | 同一世界中真人与合成智能体的数量占比；受控替换实验的自变量（H3）。 |
| 受控替换实验 | controlled substitution | 固定场景与人设分布，逐步改变真人/合成体比例，观察宏观流量演化的偏移。 |
| 多尺度接驳 | multi-scale coupling | 聚合层与个体层之间的三种连接方式：局部精化、流量校准、降维验证。 |
| 情景 | scenario | 一组空间单元、邻接、容量、吸引力与到达过程的配置；本文不使用"情境"（避免与实验情境混淆）。 |
| 效度威胁 | validity threat | 削弱结论可信度的因素，按构念/内部/外部/统计结论四类讨论（见 07 章 §7.3）。 |
| 内部效度 | internal validity | 因果归因是否成立；本文中"脚本被试"与"占位规则体"是主要内部效度威胁。 |
| 外部效度 | external validity | 结论能否推广到其他场地与人群；本文目前只在单一演示场景验证。 |
| 灰盒 | grey box | 模型结构已知、参数待标定的建模状态；本文的平台属于此类。 |

## 3. 易混术语辨析

| 易混组 | 区别 | 本文如何用 |
| --- | --- | --- |
| 存量 vs 密度 | 存量是人数（人），密度是人数/面积（人/㎡） | 模型状态用存量；界面可显示密度，但正文写"拥挤度 `x_i/C_i`"而非密度 |
| 流量 vs 流率 | 流量是每步人数（人/步），流率是每秒人数（人/s） | 全文只用流量；换算须显式写 `Δt` |
| 轮次 vs 时间步 | 轮次是实验/仿真的第几个决策周期，时间步是离散化的 `Δt` | 实验语境用轮次；数值稳定性语境用时间步 |
| 人机一致性 vs 人机一致性检验 | 前者是概念，后者是检验方法 | 概念用"人机一致性"，方法用"人机一致性检验" |
| 标定 vs 校准 | 本文只用"标定"；"校准"仅用于仪器语境 | 统一用标定 |
| 模拟被试 vs 真人被试 | 前者是脚本构造的选择，后者是真实参与者 | 06 章注入实验必须写"模拟被试"或"脚本构造的选择" |
| 合成智能体 vs 规则背景体 | 前者指 LLM 驱动，后者指零智能规则体 | 代码占位必须写"规则背景体（占位）"，不得冒充合成智能体 |
| 复现 vs 重现 | 本文只用"复现" | 统一用复现 |

## 5. 更新规则

1. 新增术语：先在本表登记（中文 | English | 定义），再在正文使用；
2. 修改定义：必须同步检查 `paper/sections/` 中所有使用处，并在提交信息中说明影响范围；
3. 术语表与 [`风格指南.md`](风格指南.md) §2 的"只允许写法"表必须一致，冲突时以本表为准；
4. 术语条目的英文名进入英文摘要前，须与 [`参考文献规范.md`](参考文献规范.md) 的
   文献题名用词核对，避免"术语一套、文献题名另一套"。
