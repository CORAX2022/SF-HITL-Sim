# Too Human to Model: The Uncanny Valley of LLMs in Social Simulation -- When Generative Language Agents Misalign with Modelling Principles

- 作者/年份/来源: Yongchao Zeng, Calum Brown, Mark Rounsevell / 2025 / arXiv preprint (2507.06310v1)
- 主题: C —— LLM 智能体用于社会仿真的方法论与认识论反思

## 研究问题
LLM 智能体在社科仿真中日渐流行，其真实感是否与建模的抽象、简化与可解释性相冲突？

## 方法
思辨性思想实验：将经典创新扩散 Bass 模型改写为 LLM 智能体版本，在改写中识别困境，无实证实验。

## 数据
无实证数据集，仅基于文献论证与单一 Bass 模型案例。

## 主要结论
提出五重困境：对话时间分辨率与抽象时间步不匹配、干预对话与智能体自发性相矛盾、提示规则化与对话自然性相张力、角色一致性与角色演化相张力、微观冗长文本掩盖系统级涌现。LLM 智能体由此陷入"恐怖谷"。

## 对本课题的可借鉴点
本课题以空间单元存量与单元间流量聚合建模，人与 LLM 智能体同处一个仿真世界。LLM 宜承担语义表达与交互角色，而非替代存量-流量更新；须保持抽象时间步与聚合指标可解释，并将微观文本汇总为系统级结论。

## 局限
属观点/思想实验类论文，无量化验证；结论基于单一 Bass 案例，普适性未说明。
