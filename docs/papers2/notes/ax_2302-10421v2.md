# Crowd simulation incorporating a route choice model and similarity evaluation using real large-scale data

- 作者/年份/来源: Ryo Nishida, Masaki Onishi, Koichi Hashimoto / 2023 / arXiv preprint (arXiv:2302.10421v2)
- 主题: D 人群仿真与移动建模；在行走行为之上补入路径选择决策，并用真实大规模数据评估复现性

## 研究问题
既有行人仿真多只建模行走这一操作层决策，路径选择所属的更高战术层决策建模不足，且缺乏用真实数据检验复现性。

## 方法
提出通用框架，串联真实移动测量、路径选择模型估计与仿真器构建三环节。路径选择用离散选择模型（DCM），行走用社会力模型（SFM）。

## 数据
两项实测：剧场疏散演练，以及数万人规模、大量移动的烟花大会。

## 主要结论
纳入路径选择模型的仿真比不含者更准确地复现真实大规模人群移动。

## 对本课题的可借鉴点
其"实测—参数估计—仿真构建"分层流程与本课题存量-流量建模互补：战术层路径选择决定单元之间的流向分配，可作个体行为与单元间流量的桥梁；以实测检验复现性的做法，可用于评估真实被试与 LLM 合成智能体共处同一世界的可信度。

## 局限
摘要未说明 DCM 的效用变量、参数误差与精度指标，也未涉及人机混合仿真；实测场景仅两项，泛化性未说明。
