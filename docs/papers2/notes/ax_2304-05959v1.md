# UAV Obstacle Avoidance by Human-in-the-Loop Reinforcement in Arbitrary 3D Environment

- 作者/年份/来源: Xuyang Li, Jianwu Fang, Kai Du, Kuizhi Mei, Jianru Xue, 2023, arXiv preprint (2304.05959v1)
- 主题: B 强化学习与人在回路（human-in-the-loop）智能体控制方法

## 研究问题

复杂三维环境中，无人机如何从起点连续导航至任意目标点（高度与速度可变），并快速学会避障。

## 方法

基于 DDPG 与 TD3 连续控制无人机三轴速度；状态含深度相机与测距传感器信息；设计基于领域知识的奖励函数，引入"避障状态"，由人类专家识别并动态调整奖励，形成 DDPG-H 与 TD3-H。

## 数据

在 UE4/AirSim 虚拟环境的 urban、rural、forest 三类场景上验证成功率与平均步长；规模摘要未说明。

## 主要结论

实验显示其缩短训练收敛时间，并提升导航效率与准确率。

## 对本课题的可借鉴点

本文将人的作用限定为"避障状态识别与奖励调整"，是轻量的人在回路接口。本课题可让真实被试与 LLM 合成智能体同处一个仿真世界，标注拥堵、瓶颈状态并在线修正单元间流量与惩罚项，使反馈落到存量-流量规则上。

## 局限

仅在无人机虚拟场景验证，未涉及行人流；专家标注的频率与一致性未说明。
