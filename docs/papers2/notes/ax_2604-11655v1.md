# RPA-Check: A Multi-Stage Automated Framework for Evaluating Dynamic LLM-based Role-Playing Agents

- 作者/年份/来源: Riccardo Rosati, Edoardo Colucci, Massimiliano Bolognini, Adriano Mancini, Paolo Sernani / 2026 / arXiv preprint (arXiv:2604.11655v1)
- 主题: C 合成人群与生成式智能体建模；面向角色扮演型 LLM 智能体的多阶段自动化评测框架

## 研究问题
常规 NLP 指标无法刻画角色贴合度、逻辑一致性与长时叙事稳定性，专业约束场景缺可复现评测手段。

## 方法
四阶段流水线：定义高层行为维度，扩写为布尔清单指标，过滤保证客观、无冗余、按智能体隔离，最终由 LLM-as-a-Judge 思维链逐项打分。

## 数据
论文提出严肃游戏 LLM Court（Unity、本地量化模型驱动 NPC），在 5 个法律情境、7 个开放权重模型上验证。

## 主要结论
框架可量化角色保真度、稳定性与推理深度权衡，并显示参数规模与程序一致性呈反向关系：8-9B 且指令微调充分的小模型可优于易迎合用户的更大模型。

## 对本课题的可借鉴点
布尔清单加 LLM-as-a-Judge 流程可迁移为合成智能体评测层：把存量守恒、按流量择路等约束写成检查项，并隔离真实被试与合成智能体指标以免互相污染。

## 局限
摘要未说明被试样本量与人类评测协议；依赖 LLM-as-a-Judge，其偏差未交代；未及存量—流量耦合群体行为。
