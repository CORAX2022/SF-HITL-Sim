# Empirical Pedestrian Safety Assessment in a Mobile Robot Using a Predictive Social Force Model

- 作者/年份/来源: Alireza Jafari, Yun-Hao Tsai, Yen-Chen Liu, 2026, arXiv preprint (2607.09192v1)
- 主题: D 行人流社会力建模与机器人—行人交互中的行人安全实证评估

## 研究问题

在 SFM 中引入预测能否同时改善机器人周边行人的客观与主观安全，尚不清楚。

## 方法

提出 PSFM 与 PTSFM，在有限时域内按匀速假设积分预测社会力矢量；在非完整约束移动机器人上实现四种变体，开展志愿者对向相遇试验。

## 数据

志愿者对向相遇试验的客观指标与交互后 Likert 问卷；样本量摘要未说明。

## 主要结论

PTTC 整合显著改善安全指标；预测作用有限，仅个别子指标可见；部分被试感到更平顺，但主观评分无显著差异。

## 对本课题的可借鉴点

该文以可解释的力机制刻画行人运动，与本课题以空间单元存量为状态、单元间流量为交换的建模相合：最小距离、最小 PTTC 与轨迹曲率可作流量的安全约束；真实被试与 LLM 智能体共存时宜双轨校验。

## 局限

仅单行人对向场景与非完整约束机器人，预测取匀速假设；样本量、数值及多行人或 LLM 智能体均未说明。
