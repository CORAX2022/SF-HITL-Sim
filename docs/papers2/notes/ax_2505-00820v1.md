# HMCF: A Human-in-the-loop Multi-Robot Collaboration Framework Based on Large Language Models
- 作者/年份/来源: Zhaoxing Li, Wenbo Wu, Yue Wang, Yanran Xu, William Hunt, Sebastian Stein / 2025 / arXiv preprint（arXiv:2505.00820v1, cs.RO；University of Southampton）
- 主题: B 人在回路与 LLM 智能体协同的异构多机器人任务分配框架

## 研究问题
多机器人系统泛化性、异构性与安全性不足，难支撑大规模部署；人常只在设定阶段介入。

## 方法
每台机器人配 LLM 智能体，理解自身能力、把任务转为可执行指令并校验；中央 assistant LLM 做子任务分配与失败后重分配；人按需介入，以 RAG 接入新机器人。

## 数据
仿真用 BEHAVIOR-1K 基准对比五种多机器人协作方法；真实世界用轮式与足式机器人测试。

## 主要结论
仿真任务成功率提升 4.76%，优于现有任务规划方法；真实部署显示零样本泛化与极少人工干预。

## 对本课题的可借鉴点
借鉴其"每单元一个 LLM 智能体＋中央协调＋人按需介入"：中央层分配单元间流量，真人与合成智能体共处一世界；执行前的可行性校验与失败后重分配，可检查流量超容量、拥堵时改派流量，并把人的干预落为规则的在线修正。

## 局限
介入频率与参与者规模无量化；指标为任务成功率，未涉及行人流等聚合流量。
