# ChatGPT vs Social Surveys: Probing Objective and Subjective Silicon Population

- 作者/年份/来源: Muzhi Zhou, Lu Yu, Xiaomin Geng, Lan Luo, 2024, arXiv preprint (2409.02601v3)
- 主题: C 用 LLM 合成"硅样本"替代真实社会调查受访者的可行性与偏差评估

## 研究问题

GPT 生成的"硅样本"在客观人口结构与主观社会态度上是否具备真实人群的总体特征。

## 方法

以 GPT-3.5-turbo 反复随机抽样生成 200 点样本、重复 30 次构造抽样分布，取均值为硅总体参数，并用 ANOVA 检验批次独立性。

## 数据

2020 年美国人口普查、ACS 五年估计，以及 2017 年 WVS 美国数据（2,596 个观测）。

## 主要结论

性别与平均年龄接近美国人口，但显著高估黑人与高学历群体，即便模型掌握正确知识；态度点估计高度不稳定、无明显意识形态倾向，回答分布呈正态且比人类更确定。

## 对本课题的可借鉴点

其"抽样分布＋基准对比"可用于校准本课题 LLM 智能体的属性保真度：以普查与调查数据核对合成智能体分布，警惕确定性过高导致多样性塌缩，并为真实被试与合成智能体在同一存量-流量空间中的可比性设定评估指标。

## 局限

基准仅限美国、以 GPT-3.5 为主，结论难外推；未涉及行人流与空间建模。
