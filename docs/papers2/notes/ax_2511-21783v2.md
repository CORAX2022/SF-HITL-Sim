# NetworkGames: Simulating Cooperation in Network Games with Personality-driven LLM Agents

- 作者/年份/来源: Xuan Qiu, 2025, arXiv preprint (2511.21783v2)
- 主题: C LLM 智能体驱动的网络博弈与社会仿真（人格异质智能体在图上合作演化）

## 研究问题

LLM 智能体在图拓扑网络博弈中如何行动，人格与拓扑怎样共定集体福利。

## 方法

把社会仿真视为消息传递：邻域聚合成社会情境 Ω，更新函数由 LLM 策略参数化，动作取决于 MBTI 人格、历史与 Ω；并在规则、小世界、无标度图上反复博弈。

## 数据

纯 LLM 智能体仿真，无实证数据；16 型 MBTI 构成异质种群，跨模型、网络规模与随机种子压力测试。

## 主要结论

宏观合作不能由 16×16 人格对的成对交互外推，而由连通性与人格分布共定：小世界捷径沦为剥削向量、破坏合作簇；无标度网络中不足 10% 的枢纽人格决定宏观结果，干预使合作率由 28% 升至 67%。

## 对本课题的可借鉴点

邻域聚合与存量-流量空间建模同构，Ω 可视为单元间流量信息，宏观量不可由微观交互外推；枢纽决定论提示将真人置于高连通单元。

## 局限

无真人被试；MBTI 效度未验证；单一博弈；网络规模未说明。
