# GPT-ology, Computational Models, Silicon Sampling: How should we think about LLMs in Cognitive Science?

- 作者/年份/来源: Desmond C. Ong, 2024, arXiv preprint (2406.09464v1)
- 主题: C 大语言模型与生成式智能体／社会仿真

## 研究问题

认知科学中围绕 LLM 的多种范式，其证据能支撑哪些推论？

## 方法

综述将文献归纳为三类范式：GPT-ology（推断模型自身能力）、LLM 作为人类认知的计算模型、silicon sampling（以 LLM 模拟人群）。

## 主要结论

同一数据可支撑不同范式推论，但各有限制：提示词敏感削弱可靠性；存在性证明逻辑不对称，模型失败不能推出必要条件缺失；模拟人类依赖保真度假设。

## 对本课题的可借鉴点

本课题让人与 LLM 合成智能体同处一个仿真世界。该文提示须区分“模拟个体”与“代表总体平均”，并报告提示词、温度等超参数、置换选项顺序，以保证人机同场实验可复现。

## 局限

该文不含实证数据，仅提出问题与框架。
