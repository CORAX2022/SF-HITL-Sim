# GSP = DSP + Boundary Conditions -- The Graph Signal Processing Companion Model

- 作者/年份/来源: John Shi, Jose M. F. Moura, 2023, arXiv preprint (2303.02480v2)
- 主题: B 图信号处理的理论方法

## 研究问题

经典信号处理（DSP）的卷积、调制、平移等运算能否在任意无向或有向图上成立，图信号处理（GSP）与 DSP 是否存在结构性等价。

## 方法

提出 GSP 伴随模型，证明 GSP 等价于 DSP 加适当边界条件；并区分基于谱频率向量 λ 逐点幂的伴随模型与基于邻接矩阵及其特征向量的图顶点模型。

## 主要结论

GSP 可视为 DSP 加边界条件；伴随模型中卷积可用 FFT 实现，适当选择载波时图调制呈现 DSP 平移效应，可实现图信号多路复用。

## 对本课题的可借鉴点

本课题的存量-流量空间模型与该框架契合：空间单元对应顶点，单元间人流对应边，守恒关系对应边界条件，可据此把人流扩散与混合计算迁移到图上，并借多路复用在同一仿真世界叠加真实被试与 LLM 智能体。
