# Structured Nonnegative Matrix Factorization for Traffic Flow Estimation of Large Cloud Networks

- 作者/年份/来源: Syed Muhammad Atif, Nicolas Gillis, Sameer Qazi, Imran Naseem, 2021, arXiv preprint (2110.07926v1)
- 主题: D 人群/交通流建模与仿真（基于空间流量矩阵的交通流估计）

## 研究问题

如何由可观测链路流量 Y 与二元路由矩阵 A（Y=AX）估计不可观测的高维 OD 流量 X；因 m≪n 该反问题病态。

## 方法

将 OD 流量映射为低维隐流量，在非负矩阵分解上叠加非负、自回归与正交（距离保持）约束，用 Nesterov 加速梯度训练；含两变体。

## 数据

两个真实骨干 IP 网络数据集 Internet2 与 GÉANT；对比 PCA、MNETME、CS-DME；指标 SRE 与 TRE。

## 主要结论

跟踪单条 OD 流量与标准指标均优于现有方法，可扩展性更佳；滞后项对降低 SRE 重要。

## 对本课题的可借鉴点

本文与存量-流量空间建模同构：链路流量即可观测聚合存量，OD 流量即单元间流量，路由矩阵 A 即单元间连通映射。非负性保证人流非负，自回归刻画日变周期；隐流量降维克服 m≪n 病态性，可为稀疏观测下初始化被试与 LLM 智能体共享的人流场提供路径。

## 局限

对象是骨干 IP 分组流非行人，未涉及个体行为与人在回路；仅离线重建验证，未做交互式仿真；依赖路由矩阵与空间特征矩阵稳定。
