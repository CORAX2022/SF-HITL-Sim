# Evidence-Grounded Multi-Agent Planning Support for Urban Carbon Governance via RAG

- 作者/年份/来源: Yuyan Huang, Haoran Li, Yifan Lu, Ruolin Wu, Siqian Chen, Chao Liu，2026，arXiv 预印本（arXiv:2601.11587v1）
- 主题: B 参与式与人在回路的交互仿真：以多智能体 LLM 加文本 RAG 构建证据可追溯、专家须在回路的城市碳治理规划支持系统

## 研究问题

城市碳治理要把排放清单、政策文本等异质证据整合为可执行方案，而 LLM 的事实可靠性与证据可追溯性不足。

## 方法

用标准文本 RAG（不用 GraphRAG）构建多智能体系统，按规划流程设证据问答、排放评估、规划推荐、报告集成四个智能体，检索证据块并附引用。

## 数据

语料含城市/区县排放与统计数据、政策文件、城市案例与学术文献；测试集 10 问，案例城市为宁波。

## 主要结论

加 RAG 后事实检索平均分由不足 6 升至 90 以上，区域与数值检出率近 100%；宁波案例专家评审三项 5/5、锚定 4/5，局限是数据库边界不一致。

## 对本课题的可借鉴点

其按流程给智能体划窄职责并强制输出证据编号，可供本课题让 LLM 合成智能体与真实被试同处一个仿真世界；存量诊断与单元间流量干预各由单一职责智能体承担。

## 局限

预印本未经同行评审；测试集仅 10 问且专家评审无统计检验，未报告真实被试实验与不确定性建模。
