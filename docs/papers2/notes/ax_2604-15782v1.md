# Fusing Cellular Network Data and Tollbooth Counts for Urban Traffic Flow Estimation

- 作者/年份/来源: Oluwaleke Yusuf, Shaira Tabassum, 2026, arXiv preprint (2604.15782v1)
- 主题: A 交通流与OD估计（多源数据融合的存量-流量矩阵）

## 研究问题

如何以稀疏准确的站点分车型计数，校正并分解聚合的手机数据，生成交通仿真所需的逐小时分车型OD矩阵。

## 方法

先由站点与线路推断定义OD节点，再用梯度提升树结合聚合移动量、时段与路型特征学习车辆计数，最后按路由规则分配流量。

## 数据

建模集为2023年11月8站点8712条样本，仿真集为2025年1月5站点。

## 主要结论

未校正手机数据相关性低，校正后总流量与各分车型决定系数均升至约0.98。

## 对本课题的可借鉴点

手机数据可作为单元间人流代理但须校正偏差；站点计数对应边界存量观测，路由规则对应单元间流量分配，与存量-流量建模同构。

## 局限

只分析机动车；建模与仿真数据时间不匹配；路由规则人工构造，每小时仅取单一主导方向。
