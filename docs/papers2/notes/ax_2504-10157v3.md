# SocioVerse: A World Model for Social Simulation Powered by LLM Agents and A Pool of 10 Million Real-World Users

- 作者/年份/来源: Xinnong Zhang, Jiayu Lin, Xinyi Mou 等，2025，arXiv preprint (arXiv:2504.10157v3)
- 主题: C LLM 智能体驱动的社会仿真世界模型与真实人群对齐

## 研究问题

LLM 社会仿真在环境、用户、交互机制与行为模式上难与真实世界对齐，缺少统一框架。

## 方法

提出 SocioVerse：社会环境注入实时事件；用户引擎维护千万级用户池与多维标签；场景引擎提供问卷、深访、行为实验、社媒交互模板；行为引擎混合 ABM 与 LLM。

## 数据

用户池由 X 与 Rednote 帖子构建，规模千万级，含 15 个属性；三场景以美国普查与 ANES、国家统计局调查等为先验。

## 主要结论

选举预测逾九成州方向正确；先验分布与用户历史知识提升精度；各模型跨领域差异明显，仿真偏负面。

## 对本课题的可借鉴点

本课题用存量—流量刻画行人空间，真人被试与 LLM 智能体同处一世界。本文按人群分布采样与先验约束构成智能体，可类比存量初始化；其模板化交互流程可支撑单元间流量规则设计。

## 局限

画像来自社媒足迹，未必代表总体；仅验证政治、新闻、经济三域；真人被试参与未说明。
