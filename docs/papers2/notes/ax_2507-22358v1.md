# Magentic-UI: Towards Human-in-the-loop Agentic Systems

- 作者/年份/来源: Hussein Mozannar 等（Microsoft Research AI Frontiers）, 2025, arXiv preprint (2507.22358v1)
- 主题: B 人机回环与参与式交互仿真（人机协同交互机制与系统设计）

## 研究问题

LLM 智能体自主能力仍不及人类，且有误对齐与对抗操纵风险，需设计低成本人机回环机制。

## 方法

提出开源 Web 界面 Magentic-UI：改编自 Magentic-One 的多智能体架构，支持浏览、代码与文件操作及 MCP 扩展；把人类视为团队特殊成员，设共同规划、共同执行、动作审批、答案核验、记忆与多任务并行六种机制。

## 数据

GAIA、AssistantBench、WebVoyager、WebGames 四基准自主评测（o4-mini 与 GPT-4o），GAIA 改造的模拟用户实验，12 人定性与安全测试。

## 主要结论

自主模式 GAIA 42.52%、WebVoyager 82.2%、WebGames 45.5%，低于人类；GAIA 加带侧信息模拟用户后完成率由 30.3% 升至 51.9%，仅 10% 求助。

## 对本课题的可借鉴点

把人类视为团队特殊成员，与本平台真人受试者与 LLM 合成智能体同处一个仿真世界一致；六种机制可映射为参与式交互层，如共同规划对应存量-流量方案确认、审批对应流量调整门禁。

## 局限

高级编程、多模态与超长网页序列任务较弱；仅英语；未测生产力收益；提示注入可致敏感信息外泄。
