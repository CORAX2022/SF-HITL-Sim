# Restoring Heterogeneity in LLM-based Social Simulation: An Audience Segmentation Approach

- 作者/年份/来源: Xiaoyou Qin, Zhihong Li, Xiaoxiao Cheng, 2026, arXiv preprint (2604.06663v1)
- 主题: C 用受众分群为 LLM 社会仿真恢复人群异质性，并以三维保真度评估分群配置

## 研究问题

LLM 社会仿真常把人群压缩为单一"平均人格"，掩盖了子群体差异。如何通过分群恢复异质性？

## 方法

介绍受众分群作为系统性恢复异质性的方法，比较六种分群配置，变化标识粒度、精简度与选择逻辑。

## 数据

使用美国气候意见调查数据，在两个开放权重模型上生成硅样本，并以分布、结构、预测三维保真度评估。

## 主要结论

粒度提升并不稳定奏效：适度标识增补可改善，过度扩张损害结构与预测保真度；紧凑配置常不逊于更全面配置；工具驱动最利于保分布形态，数据驱动最利于恢复组间结构。各维度存在权衡，没有配置全面占优。

## 对本课题的可借鉴点

对本课题：面元分群粒度应按目标设定，多做维度评估，不可一味求细。

## 局限

该文摘要未说明样本量与指标细节，数据与模型有限，结论外推受限。
