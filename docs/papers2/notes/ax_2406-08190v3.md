# CrowdEgress: A Multi-Agent Simulation Platform for Pedestrian Crowd
- 作者/年份/来源: Peng Wang, Xiaoda Wang, Peter Luh, Neal Olderman, Christian Wilkie, Timo Korhonen / 2024 / arXiv preprint (arXiv:2406.08190v3)
- 主题: D 人群疏散仿真平台手册

## 研究问题
如何模拟社会情境下的复杂人群行为，尤其是疏散中的预疏散、出口选择与从众效应。

## 方法
在社会力模型上扩展智能体模型，刻画智能体之间及与墙体、门、出口的交互；平台兼容 FDS+Evac，可导入其输入构建单层几何，并用流量求解器生成出口路径图。

## 数据
未说明实证数据集；输入为 csv 或 fds 文件，输出为兼容 fds 的二进制数据。

## 主要结论
该文属平台说明书，介绍架构与组件，未报告定量结论。

## 对本课题的可借鉴点
其智能体、障碍、仿真与界面的分层设计可迁移到本项目的存量—流量空间建模；其流量求解器生成出口路径图并兼容外部标准格式，提示单元间流向可由标准格式驱动。但平台无真实被试与 LLM 智能体共处机制，人在环层需自行设计。

## 局限
仅二维平面；社会心理模块仍属未来计划；无实证验证与定量结果。
