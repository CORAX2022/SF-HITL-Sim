# Persona Generators: Generating Diverse Synthetic Personas for Arbitrary Contexts

- 作者/年份/来源: Davide Paglieri, Logan Cross, William A. Cunningham, Joel Z. Leibo, Alexander Sasha Vezhnevets / 2026 / arXiv preprint (arXiv:2602.03545v2)
- 主题: C 合成人群与生成式智能体建模；把合成 persona 生成从密度匹配转向支撑覆盖，用代码进化提升人群多样性

## 研究问题
LLM 合成人群易塌缩为刻板、顺从的答案，既有方法偏重密度匹配而忽略长尾；本文主张转向支撑覆盖。

## 方法
用 AlphaEvolve 以 LLM 为变异算子，迭代改写 Persona Generator 代码，以多样性指标作适应度；生成器先由情境提示扩展出多样性轴，再两阶段产出人群，persona 在 Concordia 仿真中答题。

## 数据
摘要未说明真实数据集与样本量；评估使用自动生成的合成问卷，并在留出情境上测试。

## 主要结论
进化所得生成器在六个多样性指标上显著优于基线；缓解 LLM 模式塌缩后，其对真实人类特质分布的拟合优于人口统计基线。

## 对本课题的可借鉴点
"先覆盖全域、再按需重采样到目标密度"可用于本课题：把属性与偏好轴作抽样维度，先保证长尾存在，再按空间单元的目标存量分布重采样，使真实被试与 LLM 智能体在同一仿真世界中的构成可控。

## 局限
摘要未说明问卷与人口规模、指标定义及消融；人口多样性如何映射为空间单元间流量，本文未涉及。
