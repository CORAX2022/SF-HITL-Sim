# Interpreting and Steering LLM Agents for Social Simulations

- 作者/年份/来源: Jiayue Gaveal Fan, Arul Murugan, Shreyas Krishnan, Abhishek Nagaraj / 2026 / arXiv preprint (arXiv:2609.16436v1)
- 主题: C — 面向社会科学仿真的大语言模型智能体可解释性与行为调控

## 研究问题
LLM 智能体用于社科仿真时是黑箱：行为机制不可解释，也无法按需放大或抑制特定机制。

## 方法
比较提示词操控、SAE 特征引导与线性探针，用彩票游戏（风险）、最后通牒博弈（利他）、发散性创造力与产品创新四类自然语言任务操作化"偏好"与"能力"。

## 数据
模型为 Llama-3.3-70B-Instruct（第 48 层）与 Qwen-2-7B-Instruct（第 17 层），每场景对 40 个智能体重复同一引导。

## 主要结论
SAE 与探针常优于基础提示词，但面对少样本、思维链提示优势缩小；SAE 善于发现并引导未知特征，探针精确定向预设特质，二者构成"分解—定向引导"流程。

## 对本课题的可借鉴点
本课题以空间单元存量与单元间流量建模行人流，让真人与 LLM 合成体共处同一仿真世界。该文提示合成体行为须可解释、可定向调节才便于与真人对照，其"先识别机制特征、再按目标强度引导"可支撑可校准行为参数的设定。

## 局限
仅为四类经典任务上的概念验证，未涉及真人与空间流量场景；优势随提示策略而变。
