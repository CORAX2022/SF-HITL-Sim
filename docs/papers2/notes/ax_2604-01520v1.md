# LLM Agents as Social Scientists: A Human-AI Collaborative Platform for Social Science Automation

- 作者/年份/来源: Lei Wang, Yuanzi Li, Jinchao Wu, Heyang Gao, Xiaohe Bo, Xu Chen, Ji-Rong Wen / 2026 / arXiv preprint (arXiv:2604.01520v1)
- 主题: C 用 LLM 智能体搭建人机协作的社会科学研究平台，把研究流程与被试池同时"硅化"

## 研究问题
传统社会科学研究需在庞杂方法空间设计实验并依赖真实被试，昂贵难扩展；既有 LLM 研究多只作"硅被试"。

## 方法
S-Researcher 引擎 YuLan-OneSim 具三能力：自然语言经 ODD 协议自动生成可执行场景、分布式支持十万并发智能体、VR2T 反馈式微调；流程按归纳、演绎、溯因展开，研究者全程可干预。

## 数据
50 个场景覆盖八个社科领域；三案例分别复现 Axelrod 文化动态、检验教师注意力的竞争假设、经人类实验确认公共品博弈合作机制。

## 主要结论
验证通用性、可扩展性与可靠性，形成人机协作、以仿真加速社科发现的新范式。

## 对本课题的可借鉴点
ODD 自动编程与人在环干预，对应本课题参与式交互与存量-流量建模；十万级并发架构支撑大规模单元；VR2T 反馈微调校验合成智能体与真实被试的对齐。

## 局限
未说明自动编程失败率与微调开销，案例仅三个，真实被试与 LLM 智能体是否共处同一世界未说明。
