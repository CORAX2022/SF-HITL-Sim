# Beyond Demographics: Aligning Role-playing LLM-based Agents Using Human Belief Networks

- 作者/年份/来源: Yun-Shiuan Chuang, Krirk Nirunwiroj, Zach Studdiford, Agam Goyal, Vincent V. Frigo, Sijia Yang, Dhavan Shah, Junjie Hu, Timothy T. Rogers, 2024, arXiv preprint (2406.17232v2)
- 主题: C 用 LLM 智能体做社会仿真并使其行为对齐真实人群

## 研究问题

仅凭人口学信息角色扮演的 LLM 智能体难以重现人类意见，能否借实证信念网络改善对齐。

## 方法

用人类调查做因子分析，得到 64 个议题载荷于 9 个潜在因子的信念网络；为受访者构造数字孪生智能体并注入观点，比较无人口学、仅人口学、人口学加单一信念三种条件，并对比提示与微调。

## 数据

取自 Controversial Beliefs Survey，含 64 个信念陈述与六点李克特量表，对照为人类受访者作答。

## 主要结论

人口学角色扮演无法对齐人机意见；注入单一信念后网络内议题对齐显著改善，网络外则否。

## 对本课题的可借鉴点

本课题让真实被试与 LLM 合成智能体共处同一仿真世界；本文提示智能体画像不应只含人口学属性，更应注入锚定态度作为个体存量，再经单元间交互流量传播以保持一致。

## 局限

只评估 64 个信念议题上的意见对齐，未涉及多智能体交互、外部效度与空间建模。
