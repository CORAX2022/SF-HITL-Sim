# LLM-Agent-based Social Simulation for Attitude Diffusion

- 作者/年份/来源: Deepak John Reji (University of Limerick 社会学系), 2026, arXiv preprint (2604.03898v1)
- 主题: C LLM 生成式主体建模与社会仿真（移民态度扩散与极化）

## 研究问题

突出事件后公众对移民态度如何演变？传统主体建模以固定规则更新观点，无法处理语言与时事。

## 方法

开源框架 discourse_simulator：主体持经济、文化、安全、人道四维信念，在小世界网上运行观察—思考—行动循环，检索实时新闻生成帖子，再由 LLM 打分并更新态度。

## 数据

100 智能体、15 天仿真，关键事件为 2025-04-26 都柏林反移民游行；主体比例依爱尔兰调查校准，新闻在线检索。

## 主要结论

自称首个爱尔兰事件后移民话语动态的生成式仿真，定位为理论检验工具而非预测黑盒；正文只含框架设计，无结果章节。

## 对本课题的可借鉴点

四维信念加心理惯性把存量（态度分布）与流量（同伴影响、新闻冲击）分开，其更新式可改写为存量更新方程；工具调用与推理分离，便于真人被试与 LLM 智能体统一接口。

## 局限

该 PDF 无结果与验证章节；案例仅单事件、100 智能体、15 天，未涉及行人流动与真人实时交互。
