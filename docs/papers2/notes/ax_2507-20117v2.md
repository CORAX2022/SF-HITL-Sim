# RESCUE: Crowd Evacuation Simulation via Controlling SDM-United Characters

- 作者/年份/来源: Xiaolin Liu, Tianyi Zhou, Hongbo Kang, Jian Ma, Ziwen Wang, Jing Huang, Wenguo Weng, Yu-Kun Lai, Kun Li；2025；arXiv preprint（arXiv:2507.20117v2, cs.CV）
- 主题: D（人群疏散仿真：三维多智能体决策机制与个性化运动控制）

## 研究问题
现有疏散模型忽略碰撞、人际交互及地形与体型差异，难以在线模拟大规模个性化三维疏散。

## 方法
对齐人脑“感觉—决策—运动”（SDM）环路，提出实时三维仿真框架：三维自适应社会力模型（SFM）决策机制（含避让力）与个性化步态控制，支持多智能体并行，并提出部件级受力可视化。

## 数据
该文摘要未说明具体数据集，仅称在多种疏散场景验证并公开代码；正文提及人群密度、走廊宽度与地形影响。

## 主要结论
各智能体可全过程动态规划轨迹与个性化行动，兼容不平整地形，支持数百智能体实时并行。

## 对本课题的可借鉴点
其“感知—决策—运动”分层可作人在回路仿真的智能体骨架，使真实被试与 LLM 合成智能体共存同一世界；个体社会力运动可聚合为空间单元间流量，与存量—流量建模互补。

## 局限
摘要未给出定量指标及与真实疏散数据的对比；未涉及真实受试者参与或人机混合实验。
