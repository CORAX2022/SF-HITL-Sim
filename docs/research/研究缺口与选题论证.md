# 研究缺口分析与选题论证

> 本文档把项目的研究定位讲清楚：既有工作做到了什么、缺口在哪、
> 本项目如何填补。文献证据由 Lane E 在 `docs/literature/` 中提供，
> 本文档引用其结论时标注出处；尚未取得文献支撑的判断标注为**待证**。

---

## 1. 四条既有研究脉络及其边界

### 脉络一：精细人群空间仿真

**代表路线**：精细地理数字孪生、个体元胞自动机、行人动力学（社会力/RVO）。

**已做到**：高保真复现个体物理移动；可评估局部密度、瓶颈、疏散时间。

**边界**：
- 空间建模与个体参数是**两个独立成本中心**，工程投入高；
- 状态维度随人数增长，大规模长时间推演代价高；
- 多为**单向推演**：设定初值 → 计算 → 输出，缺少把人的实时决策嵌回循环的机制；
- 主观感知（拥挤感、安全感、偏好）**不在模型内**，只能事后问卷补充。

> 这一脉络解决了"人在空间里怎么走"，但没有解决"人怎么想、以及想法如何改变系统"。

### 脉络二：存量-流量 / 系统动力学空间建模

**核心思想**：以聚合单元存量 + 跨单元流量替代个体追踪（见
[`docs/model/存量-流量模型规范.md`](../model/存量-流量模型规范.md)）。

**已做到**：显著降低空间建模复杂度；天然适配 O-D 矩阵与重力模型的成熟工具链；
国际上已用于城市集会、公共设施人流压力评估等情景。

**边界**：
- **与参与式仿真实验深度结合的案例很少**（本项目的核心切入点）；
- 参数（吸引力、成本敏感度）依赖标定，标定数据常来自观测而非实验；
- 人的异质性被聚合压缩。

> 这一脉络解决了"如何低成本刻画空间人流"，但没有解决"如何把真实人的
> 实时决策与主观感知接进这个低成本模型"。

### 脉络三：人-在-回路（HITL）参与式仿真

**已做到**：在计算社会科学、应急推演、公共规划中把人类受试者嵌入仿真闭环，
实现人类决策与仿真环境的**双向动态交互**。

**边界（三个断裂）**：
1. **空间断裂**：行为科学界广泛使用 oTree 等工具做受控 HITL 实验，
   能高效采集选择偏好，但**多数实验局限于博弈、公共决策等非空间情景**，
   很少与空间流量仿真模型耦合；
2. **学科断裂**：规划学科内部的参与式实践**仍多停留于纸质沙盘、问卷访谈等静态模式**，
   尚未形成"人类提交空间选择 → 聚合驱动仿真 → 仿真空间状态回传参与者"
   的动态闭环实验范式；
3. **规模断裂**：受试者数量有限，难以代表群体。

> 这一脉络解决了"人进闭环"，但没有解决"空间性"与"规模性"。

### 脉络四：LLM 合成智能体群体仿真

**已做到**：伴随大模型技术发展，涌现一批基于 LLM 构建合成智能体群体的仿真工作，
用以复现社会群体行为、开展反事实情景推演。国内已有大模型驱动的合成智能体
仿真平台（赛博ZJU、SocioVerse 等），可构建虚拟群体复现内部社会行为与人流演化。

**边界**：
- **多数合成智能体仿真实验仍以纯虚拟计算主体运行**；
- **真实人类受试者与合成智能体共同驻留同一仿真环境开展协同推演的案例仍然有限**；
- 合成体的行为**外部效度存疑**：LLM 产出的选择分布与真人是否一致，缺少直接实证。

> 这一脉络解决了"规模性"，但引入了"代表性/真实性"问题，且没有真人对照。

## 2. 缺口的结构化表述

把四条脉络按三个维度打分（✔ 已解决 / △ 部分 / ✘ 未解决）：

| 脉络 | 低成本空间建模 | 真人进闭环 | 群体规模 | 主观感知数据 | 空间性闭环 |
|---|---|---|---|---|---|
| ① 精细人群仿真 | ✘ | ✘ | △ | ✘ | ✘ |
| ② 存量-流量建模 | ✔ | ✘ | ✔ | ✘ | ✘ |
| ③ HITL 行为实验 | — | ✔ | ✘ | ✔ | ✘ |
| ④ LLM 合成智能体 | △ | ✘ | ✔ | ✘ | △ |
| **本项目** | **✔** | **✔** | **✔** | **✔** | **✔** |

**核心缺口（一句话）**：

> 现有研究缺少一个把**存量-流量聚合空间模型**、**真人被试在回路**、
> **LLM 合成智能体**三者整合到**同一仿真环境**的实验平台；
> 因而既无法以低成本方式开展空间人流情景推演，
> 也无法在闭环中同步采集真实参与者的客观时序空间选择与主观感知偏好，
> 更无法回答"合成智能体能否在人群仿真中替代真人"这一关键问题。

三个**子缺口**：

- **G1（范式缺口）**：存量-流量范式未与参与式仿真深度结合，
  其"低成本 + 天然流量语言"的优势未被用于人机交互实验。
- **G2（闭环缺口）**：规划参与式实践缺"选择提交 → 仿真推进 → 状态回传"的动态闭环；
  行为科学实验缺空间性。
- **G3（混居缺口）**：真人与合成智能体共同驻留同一环境协同推演的案例有限，
  缺少人类决策对仿真过程的**实时反馈与约束**。

## 3. 本项目如何填补

### 3.1 针对 G1：把人的决策当作"流量源"

在存量-流量模型里，人的空间选择**本身就是流量**。
因此接入真人不需要改造模型结构，只需在流量合成处增加一项
（数学规范 §3.2）：

```
f_ij(t) = f_ij^bg(t) + f_ij^human(t) + f_ij^llm(t)
```

这使"降低空间建模复杂度"与"引入真实决策"这两个目标**不冲突**——
是本项目最关键的可行性论证。

### 3.2 针对 G2：定义闭环实验范式

明确闭环时序（数学规范 §5）与统一决策协议（架构文档 §3）：

```
呈现状态 → 采集选择 → 聚合为流量 → 约束投影与推进 → 状态回传
```

并同步采集三层数据：客观选择与反应时、主观感知量表、决策理由文本。
使平台同时是**推演工具**与**实证数据采集装置**。

### 3.3 针对 G3：单一世界 + 同构接口

真人被试与 LLM 合成体通过**完全相同的决策协议**接入**同一个**仿真世界
（架构文档 §1）。由此支持：

- **受控替换实验**：固定场景与人设，把真人/合成体混合比例从 100%/0%
  扫到 0%/100%，测量宏观流量演化的偏移；
- **直接外部效度检验**：同一场景下真人群体与合成体群体的流量分布差异；
- **互补实验**：小样本真人提供行为基准，合成体扩展到群体规模。

## 4. 预期贡献

1. **范式贡献**：提出"存量-流量聚合空间模型 + 人机混合在回路"的动态闭环
   实验范式，填补 G1/G2。
2. **平台贡献**：可运行的开源实验平台（网页端交互实验 + 聚合仿真 + 数据采集），
   支持真人被试与合成智能体同场推演，填补 G3。
3. **实证贡献**：
   - 真实参与者的**客观时序空间选择**与**主观感知偏好**配对数据集；
   - **拥挤弹性**等行为参数的实验估计（替代传统观测标定）；
   - **人机一致性**实证：合成智能体在人群空间决策上的可替代性边界。
4. **方法贡献**：聚合近似相对个体仿真的误差量化路径
   （多尺度接驳，数学规范 §7）。

## 5. 可证伪的假设（供实验检验）

| 编号 | 假设 | 检验方式 | 证伪条件 |
|---|---|---|---|
| H1 | 人对拥挤的响应在聚合模型中可通过 `p_i`、`Attr_j` 参数化 | 实验估计参数并回代预测留出轮次 | 参数不稳定，预测误差无改善 |
| H2 | 揭示偏好（客观选择）与陈述偏好（量表）存在系统性偏离 | 配对比较、偏离度分布 | 两者高度一致且无系统偏差 |
| H3 | LLM 合成体在低拥挤情景下接近真人，在高拥挤/高风险情景下显著偏离 | 混合比例扫描下的流量分布检验 | 各情景下均无显著差异，或差异与情景无关 |
| H4 | 存量-流量聚合演化在单元尺度上能复现个体模型的宏观统计量 | 同场景双模型对照 | 宏观统计量（峰值、再分配比例）显著不一致 |
| H5 | 状态回传内容的设计（是否给他人选择信息）显著影响被试决策 | 组间对照实验 | 决策分布无显著差异 |

> H1–H5 均可由本平台直接检验——这正是平台价值的体现：
> 它不只是"跑情景"，它**生产可证伪的行为科学证据**。

## 6. 与既有平台的关系（定位）

| 平台/工具 | 空间流量仿真 | 真人闭环 | LLM 合成体 | 本项目关系 |
|---|---|---|---|---|
| oTree / jsPsych | ✘ | ✔ | ✘ | **复用**其被试接入与量表机制 |
| Mesa / Agents.jl | △（需自建聚合层） | ✘ | ✘ | **复用**其调度与数据采集骨架 |
| AgentSociety 等 | △ | ✘ | ✔ | **复用**其智能体记忆与 LLM 编排，补上真人通道 |
| SUMO / CityFlow / AB Street | ✔（精细） | ✘ | ✘ | **对照与接驳**，非运行内核 |

结论：本项目不是从零造轮子，而是**在既有成熟组件之上补齐"真人 + 空间存量流量 + 合成体同场"这一缺失组合**。
