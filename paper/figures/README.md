# 图件目录说明（paper/figures/）

> 本目录存放**论文正式使用的图件**。当前目录为空：现有图件都还留在仓库的
> `results/repro/` 与 `docs/` 中，是否复制/加工到本目录由 06 章定稿时决定。
> 任何图件在进入本目录前，必须先确认其数值来源与许可。

---

| 来源类型 | 位置 | 可用性 | 注意事项 |

## 2. 命名规范

**格式**：`fig-<章号两位>-<序号两位>-<英文简述>.<扩展名>`

示例：

```
fig-03-01-closed-loop.png
fig-03-02-space-partition.svg
fig-04-01-architecture.svg
fig-06-01-nlogo-remaining-agents.png
fig-06-02-exit-time-boxplot.png
fig-06-03-peak-density.png
fig-06-04-exit-time-mean.png
```

规则：

- 只小写字母、数字与连字符；
- **一个图只对应一个文件**，不出现 `final`、`final2`、`new` 等版本后缀；
  版本由 git 承担；
- 矢量图优先（`.svg`/`.pdf`），位图 `.png` 分辨率不低于 300 dpi；
- 图中文字体与正文一致（中文用系统可用黑体/宋体，英文 Times New Roman 或等价）；
- 图内不得出现中文乱码（生成时显式指定字体，参见 `scripts/plot_nlogo_repro.py` 的做法）。

## 5. 图件在 Markdown 中的引用方式

```markdown
![图 6-1 三模式剩余人数演化曲线对比（作者 vs 复现）](figures/fig-06-01-nlogo-remaining-agents.png){#fig-06-01}

如图 6-1 所示，……
```

> 上例中的 `figures/fig-06-01-nlogo-remaining-agents.png` 是**示例路径**：
> 该文件尚未复制到本目录（现存图件仍在 `results/repro/fig1_*.png`），
> 在复制与改名完成前，正文不得按此路径插图。

- 图片路径相对 `paper/` 根目录；导出时由 `--resource-path=paper` 解析；
- 图注格式遵循 [`docs/writing/风格指南.md`](../../docs/writing/风格指南.md)
  §4：`图 <章>-<序号> <中文题名>（必要时补充来源/许可）`，题注置于图下方；
- 引用图时用"如图 6-1 所示"，不用"见下图""上图"；
- 交叉引用编号在 pandoc 的 DOCX/PDF 输出中由 `--number-sections` 与标题编号承担，
  **图号需人工保持一致**（当前未引入 pandoc-crossref）。

**禁止**：使用未署名的第三方截图；使用未获授权的图片素材；把他人图件改色后
当作自制图。

## 7. 图件与版本

- 图件与其数据快照**必须与稿件同一 tag**（`vX.Y.Z` 或 `draft-YYYYMMDD`）；
- 重新生成图件前先提交数据快照，确保"图—数据—代码版本"三者可对应；
- 修改图件必须在提交信息中说明原因（`docs(figures): 修正图 6-2 坐标轴单位`）。
