# 表格目录说明（paper/tables/）

> 本目录存放论文正式使用的**表格片段**（可选）。当前目录为空：各章表格以内联
> Markdown 表格形式写在章节文件里，只有在需要复用、需要单独校样或需要多格式导出时，
> 才把表格抽到本目录。抽取与引用规则见 §3。

---

## 1. 表格的两级组织

| 级别 | 位置 | 适用场景 |
| --- | --- | --- |
| 内联表（默认） | 直接写在 `paper/sections/*.md` 正文中 | 绝大多数表格；改稿时与正文同步修改 |
| 独立表（按需） | 本目录 `tab-*.md` / `tab-*.csv` | 多章复用、超长表格、需要单独给制版/编辑部时 |

**原则**：能内联就内联，避免"表在 A 处、引用在 B 处、数据在 C 处"三处漂移。

---

## 2. 命名规范

**格式**：`tab-<章号两位>-<序号两位>-<英文简述>.<扩展名>`

示例：

```
tab-02-01-capability-matrix.md
tab-02-02-hypotheses.md
tab-04-01-implementation-status.md
tab-06-01-conservation-checks.md
tab-06-02-human-injection-effect.md
tab-06-03-nlogo-reproduction.md
tab-07-01-open-questions.md
```

规则：

- 只小写字母、数字与连字符；不出现 `v2`、`final` 等版本后缀（版本由 git 承担）；
- 表格的数据源写在表格上方的注释或表注中（不写"见数据文件"这类模糊指代）；
- 一个表只对应一个主题，不把"结果 + 讨论"塞进同一张表。

## 3. 表格写法约定

### 3.1 内联表格式

```markdown
表 6-1 三种条件的守恒性检验（200 轮）

| 条件 | 轮数 | 最大总量漂移 | 判定 |
| --- | --- | --- | --- |
| A 纯背景流 | 200 | 9.734e-13 | PASS |

注：漂移为"总量变化 − 边界净流入"的绝对值最大值；数据源 `data/demo/loop_demo_summary.json`。
```

约定：

1. **表题在表上方**，格式 `表 <章>-<序号> <中文题名>`；
2. **表注在表下方**，以"注："开头，写清口径、单位与数据源；
3. 数字列右对齐，文本列左对齐（在 Markdown 表头分隔行用 `---:` 控制）；
4. 数值精度**全表统一**（如统一 3 位小数或统一科学计数法），不得同一列混用；
5. 百分比与变化率须注明符号约定（`+` 表示上升）；
6. 空值写 `—` 或 `未测`，不得留空导致读者误读为 0。

### 3.2 独立表格式（`tab-*.md`）

独立表文件只含三部分：

```markdown
<!-- 数据源：data/demo/loop_demo_summary.json（生成时间与 commit 见同 tag 的数据快照） -->

| 条件 | 轮数 | 最大总量漂移 | 判定 |
| --- | ---: | ---: | --- |
| A 纯背景流 | 200 | 9.734e-13 | PASS |

注：<口径说明>。
```

正文引用方式：

```markdown
{{#include tables/tab-06-01-conservation-checks.md}}
```

> **注意**：上述 `{{#include}}` 是文档工程工具的语法，pandoc 不识别；
> 使用 pandoc 导出时须改为在构建脚本中先做文本拼接（见
> [`paper/manuscript.md`](../manuscript.md) §4），或在定稿时直接把表格内联回章节文件。
> **当前默认策略是内联，独立表仅作校样用途。**

### 3.3 导出为三线表

DOCX/PDF 中的三线表由样式模板控制（`--reference-doc`），当前模板**尚未创建**；
在模板就位前，导出稿中的表格使用默认样式，属于已知待办，不影响内容审阅。

## 5. 数据来源与真实性

- 表格中每个数字都必须能指到 `paper/README.md` §8 素材表中的某个文件；
- 引用他人文献的表格（如表 2-1、表 2-2）只转录已核验的判断，**不得把作者推断
  写成文献结论**；
- 若表格数据来自运行脚本（如守恒检验），须在表注中写明脚本路径与运行参数，
  使读者可复跑；
- 外部模型复现的表格须同时标注"复现自第三方模型"及其许可（CC BY-SA 4.0）。

---

## 6. 表格与版本

- 表格与其数据源、图件、正文**必须与稿件同一 tag**（`vX.Y.Z` 或 `draft-YYYYMMDD`）；
- 改动数值必须同时改：源数据文件（若可变）、章节表格、表注中的口径说明、
  以及正文引用的数值——**四处缺一即为不一致**；
- 提交信息示例：`docs(tables): 表 6-3 补注 door-width 取值依据`。
